# Whole-corpus composition helps exports, but does not close more packages

The experiment now covers all **97 pinned packages on none, browser and node**,
using the already verified `124c3fd58` implementation. No further engine change
was made. Composition remains promising as an additional certification path;
this experiment does **not** establish a route to every package or justify
replacing the existing mixed proposal/graph path.

Relative to the retained checkpoint, there are **five additional clean exports
on each of none and browser, and fifteen on node**. All-host complete surfaces
remain **1/97**, `@solid-primitives/platform`. Cursor has a complete node
surface, confirming the earlier smaller experiment, but stays open elsewhere.
These are experimental surfaces, not production tier or criterion-3 results.

| Host | Retained checkpoint clean | Observed graph clean | New clean exports | Existing clean exports not observed | Observed exports becoming open |
| --- | ---: | ---: | ---: | ---: | ---: |
| none | 102 | 75 | 5 | 32 | 0 |
| browser | 103 | 76 | 5 | 32 | 0 |
| node | 135 | 118 | 15 | 32 | 0 |

The 32 missing clean exports are constants in `@solid-primitives/share`. Its
retained install lacks `@solid-primitives/utils`, so the forced graph cannot
prepare. The existing mixed path retained those constant exports. They are
**unobserved here**, not evidence that a soundness proof regressed. Do not add
the graph gains to the checkpoint headline and call the sum a new measurement:
the combined production transaction and environment admission were not run.

## Whole inventory, exact graph transactions

All **721 expected export addresses** are accounted for per host: 619 have
observed native-published surfaces; 102 remain unobserved behind ten explicit
package refusals. No extra export addresses appear. A missing export or a
refused graph cannot count as clean or complete. Native self-admission must
also succeed for every expected entrypoint before a package counts as complete.

The ten refused packages are:

- Animation and form: retained root proposals unavailable. This experiment
  does not invent a reason for the missing artifact.
- Controlled-props, drag-drop, favicon, upload and virtual: the exact graph
  imports `solid-js/web`, which the pinned package does not export.
- Filesystem: its retained install lacks `@tauri-apps/api`.
- Keyed and share: their retained installs lack `@solid-primitives/utils`.

Every semantic proposal was generated by the native producer. Exact archives,
lock selections, private Type Facts programs, census, veto, native publication
and self-admission remain the authority. The runner is offline: an unavailable
archive refuses instead of fetching or installing. It checks that generation
inputs remain byte-identical throughout each transaction. No proposals were
authored, edited or revived after refusal.

The measurement readers initially made two reporting mistakes, corrected
without repeating certification or changing the original evidence: counting
only callable `clean` states rather than also proven noncallable `value`
states, and expecting a plain catalog for multi-entrypoint case-set publication.
The final comparison reads the publisher's named pointers and checks document
and catalog byte digests. It never scans for a more favorable receipt. Open
cases cannot be overridden by a later closed case.

SSE's retained proposal omitted its recovered main entrypoint. Three additional
transactions measure only that missing entrypoint, preserving the original
worker runs. Future runner invocations take inventory from both the retained
proposal and the checkpoint's measured entrypoint addresses. Inventory does
not supply semantic claims.

## A real consumer limitation after closing an export

Five strict TypeScript 5.9.3 specimens against published
`event-bus@3.0.0-next.3` and Solid/signals/web 2.0.0-rc.9 pass. Thirty checker
analyses compare compiled-tier and generated-receipt consumers across hosts.
The generated receipts are admitted in every consumer analysis.

- A simple `batchEmits({ emit: () => 1 })` call and calling that result's
  `emit` both certify cleanly on all hosts. Their baseline has SC9005.
- An untracked signal read hidden inside the caller's `emit` remains SC1001
  **uncertifiable** on all hosts. The JSX twin also remains uncertifiable;
  neither gets a fabricated violation or silent certification.
- A direct untracked signal read still produces SC1001 **violation** on all
  hosts. All snippets pass the real typings, so this is not a tsc duplicate.

The accepted return operation already names parameter zero as its output.
Returning the same object alone is insufficient evidence that an external
call preserved its members. The experiment therefore distinguishes closing
the wrapper's call domains from proving reads through the returned object.
There is **no criterion-3 gain** from these consumers.

An isolated parameter-preservation claim experiment has been proposed to the
owner under the instruction to ask before a new claim form or value shape.
It has not been implemented or treated as approved. Existing claims remain
unchanged.
