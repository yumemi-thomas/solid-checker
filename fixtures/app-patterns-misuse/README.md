# app-patterns-misuse

A recall ledger for application code: plain-Solid misuse patterns from real
apps, each with a misuse twin and a correct twin of one component.
`cases.json` is generated by `build_cases.py`; `corpus-twins.json` holds more
pairs, each modelled on an rc.13 corpus site and naming the `install` whose
`node_modules` it imports from (`run-corpus-twins.sh` runs one pass per install).

```sh
SOLID_CHECKER_NATIVE_BIN=... SOLID_TYPEFACTS_BIN=... \
MISUSE_CASES_ROOT=<an install with the audited Solid release>/.solid-checker-app-patterns \
node benchmarks/reviewed-package-models/development/misuse-runtime-ledger.mjs out.json <chromium> \
  --cases fixtures/app-patterns-misuse/cases.json
```

A case's runtime verdict is `detected` when the misuse twin raises the Solid
dev diagnostic its rule implies and the correct twin raises none. Its static
verdict is the checker's finding for that rule on the misuse twin; a violation
on the correct twin is `false-positive-on-correct`. Two cases
(`on-settled-read`, `signal-in-tracked-effect`) raise no runtime diagnostic and
stay statically silent.
