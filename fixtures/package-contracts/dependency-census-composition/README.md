# A dependency creates claim must reach an authenticated receipt

The native test packs these sources into two exact published-artifact fixtures.
The parent calls an aliased dependency export. Its census may name the exact
child creates claim as an obligation, but finalization must authenticate the
child receipt and require that claim closed and empty. An open child contract
and a child whose mandatory veto was not run leave the parent open.

The callable argument is caller-supplied in both declarations. These files
exercise certification rather than adding a diagnostic or a generated-main
snapshot. The existing composition tests cover stale epochs, substituted
receipts, missing exact claims, and graph transplantation.
