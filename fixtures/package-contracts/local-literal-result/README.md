The native certification regression packs each runtime with the declaration
into an exact published archive and runs the live producer, creates census,
synthesized veto and receipt finalizer. Only `complete.js` closes: every
return names the same unwritten local allocation. It exercises both a write
and a read of the returned object. The other cases preserve mixed return,
fallthrough, accessor and replacement refusals. Keys remain strings rather
than literals so the compiler records the computed access form.

Producer tests additionally cover cross-file aliases, async and generator
completions, module allocations, rewritten result bindings, and nested member
reads, and assert that the forms are actually recorded.

The `factory*.js` cases exercise a separate returned-callable derivation:
one expression-bodied factory returns one exact callable, capturing stated
primitive arguments. The positive case closes; changed factory/result
bindings, a written capture, and an object capture remain refused. The
anonymous-body producer test independently binds the compiler symbol and
rejects a shifted demand span.
