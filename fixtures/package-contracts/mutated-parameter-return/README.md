# Returning a parameter binding does not always return its input value

This is a source proposal fixture, matching the alpha source subpath that
exposed the overclaim. It is not a successful runtime probe over TypeScript.
The private ancillary object activates the existing structured-return pass,
which also runs in the real bundle. Its unrelated presence must not make a
mutated input acquire a false identity relation.

Direct keeps its exact argument-return proposal. Assignment, update, nested
write, alias, default, destructuring and async wrapping withhold that identity.
An unknown return is not a negative claim. The declarations are complete
signatures and do not loosen the runtime relationship. Native identity tests
and producer controls reject mismatched/mutated identities independently.
