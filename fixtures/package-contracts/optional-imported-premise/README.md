# Optional imported type premise

The exported signature names `Axis | undefined`; the JavaScript helper has
no in-scope name for Axis. Its generated twin needs a complete import-type
spelling for the union. A packed native archive test requires the numeric
case to close creates after the helper's coercion clears. The `unknown.d.ts`
control preserves that coercion and stays withheld.

Producer tests also verify that the unpremised form exists and that swapping
undefined for null or replacing Axis with a same-named interface from another
declaration module cannot pass the premise echo. Union identity includes
every constituent rather than only the outer union flag.
