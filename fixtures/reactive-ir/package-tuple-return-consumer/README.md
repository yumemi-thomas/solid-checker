# A consumer reading through a wrapper into a reactive tuple

Written to pin `Dialect::returns_reactive_tuple` through an `identity` wrapper whose contract returned argument 0: signal, store and projection reads would give SC1001, while elided-slot and whole-tuple bindings stay clean. Package contracts are removed (ADR 0312), so nothing sees through `identity` any more. Today the only finding besides the SC9014 notice for the rc.0 stub is `SC9012` `reactive-dispatch-unresolved` (uncertifiable) at `SignalSlot`'s `value()` read; `ElidedSlot`, `StoreSlot`, `WholeTuple`, `Projection` and `Writes` are silent, so the tuple-shape claim is no longer pinned. `solid-js.d.ts` quotes the audited return shapes (only `Refreshable` dropped; nothing looser). The `solid-reactivity.json` beside the stub is inert.
