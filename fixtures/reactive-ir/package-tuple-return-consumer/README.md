# A consumer reading through a wrapper into a reactive tuple

Pins `Dialect::returns_reactive_tuple` at the behaviour level through an accepted `identity` contract (ADR 0282: unresolved calls with a possible intrinsic receiver make `SignalSlot`/`StoreSlot` uncertifiable): signal, store and projection reads give SC1001; elided-slot and whole-tuple bindings stay clean (without the row they would invent SC1001); `createProjection` returns the store itself so its absence from the tuple list is deliberate. `solid-js.d.ts` quotes the audited return shapes (only `Refreshable` dropped; nothing looser); manifest from `package-return-consumer`.
