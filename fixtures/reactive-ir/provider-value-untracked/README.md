ADR 0401: Solid 2's context element reads `value` once, when its function runs under the strict-read window (`<provider>`), and stores that snapshot; a child's `useContext` subscribes to nothing, so a later write never reaches it. `App.tsx`: SC1001 at a signal read written directly in `value`, at a memo accessor read there, and at a read in `value` of a context a project file imports (`Contexts.ts`); none for a function value (stored, not run), `untrack`, a plain constant, or a read the child makes inside JSX. `Shadowed.tsx`: a project component named like a context but not made by `createContext` is not a provider. `props.value` reads follow their callers (`strict-read-untracked`, props).
