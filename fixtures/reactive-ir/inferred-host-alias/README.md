# Inferred host: alias

Browser-only document (copy of `inferred-host-spa`) reached through a tsconfig-only path alias, which is not a runtime edge: browser admission is withheld, so the snapshot is `certified` with no finding (an admitted host would make it `uncertifiable`, as in `inferred-host-spa`). Every non-type static import must link before the module can evaluate, and unknown or unloadable requests keep baseline.
