# Inferred host: alias

Browser-only document (copy of `inferred-host-spa`) reached through a tsconfig-only path alias, which is not a runtime edge: admission is baseline; every non-type static import must link before the module can evaluate, and unknown or unloadable requests keep baseline. Explicit browser is the control. `startClosed(): void` states an ownership requirement TypeScript cannot express; no published signature is loosened.
