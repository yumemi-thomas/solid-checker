# change-checkbox-misuse

**Claim (ADR 1148).** The `change` handler of a literal `<input type="checkbox">` or `<input type="radio">` is delivered by its click activation alone: a user's click, the Space key or an arrow key on the host's stack, or a call the dispatch census already counts (`el.click()`, `label.click()`, `dispatchEvent`). So its body is an event callback with no owner, as a `click` handler's is. A text control is delivered `change` by any way the focused element leaves (`blur()`, `remove()`, `disabled = true`, Solid's own unmount), in the call (ADR 0642), and a checkbox retyped to text is one. Chrome 148, measured: `docs/decisions.md`, ADR 1148.

- **Proved violations**: a `createEffect` in the handler of a literal checkbox and of a literal radio creates an effect with no owner: SC4001 `missing-owner` is a violation at each (on the base it was uncertifiable, `denied-event`). Chrome warns NO_OWNER_EFFECT at both (runtime-oracle `change-checkbox-misuse`).
- Still uncertifiable: SC6002 `effect-creation-unaccounted` at each, which no proof of this slice touches.

Twins, each its own project: proved `change-checkbox-handler` (the setters and a row's `index()` read are legal: no row), `change-checkbox-misuse` (a `createEffect` there is a proven SC4001 violation) `change-dependency-plain` (the same beside a loaded dependency that writes nothing of the kind) `change-local-setproperty` (the same beside a function named like a runtime writer) and `change-attr-node-control` (the control of `change-retyped-attr-node`: the same program without the lines that reach the Attr node, certified); kept uncertifiable `change-element-denied`, `change-attr-namespace` (the element decides), `change-retyped-assignment`, `change-retyped-attribute-api`, `change-retyped-computed-key`, `change-retyped-lookup-setter`, `change-retyped-folded-name`, `change-retyped-dependency`, `change-retyped-runtime-writer`, `change-retyped-runtime-writer-alias`, `change-retyped-attr-node`, `change-retyped-frames` (the program decides) and `change-dispatch-veto`, `change-delivery-hazard` (the premises ADR 1125's veto and delivery check ask); runtime-oracle `change-checkbox-legal` (quiet) and `change-checkbox-misuse` (Chrome warns NO_OWNER_EFFECT at each site); textbook `cs-form-input` and `id-todo-for` (certified).
