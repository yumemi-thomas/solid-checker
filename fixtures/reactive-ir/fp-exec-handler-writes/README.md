# fp-exec-handler-writes

**Claim.** A signal write is a proven owned-scope write (`SC2001`) only where facts place it in a phase under an owner: event handlers (JSX attribute function values, however wrapped), closures kept in values a tracked scope returns, closures in leaf callbacks (`createTrackedEffect`, `onSettled`), `onCleanup` callbacks and code after an `await` are never violations: where a fact places them (a leaf callback, `onCleanup`) they produce no finding, and where none does (a JSX attribute function, a stored closure, code after an `await`, a hook with no caller) the write is uncertifiable; writes in the body, helpers called in it, memo bodies, IIFEs and before an `await` are violations. Stub copies `createSignal`, `createMemo`, `createTrackedEffect`, `onCleanup`, `onSettled`, `untrack` from published rc.9.
