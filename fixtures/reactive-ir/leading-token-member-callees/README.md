# leading-token-member-callees

**Claim (ADR 0376).** A getter's callee is the accessor only as its identifier: `s.toString()` reads nothing (before: SC1001 through `readsA`), `String(s())` stays a violation. SC9011 does not drop a reactive argument because the callee span names no symbol: a callee led by `(` or `new` has none, and the resolved call decides (`(flag ? apiA : apiB).register(count)` and `new Registry().register(count)` were certified; now SC9011 like `apiA.register(count)`). A class heritage names its base only as an identifier: `extends Holder.Base` is `Swap`, whose constructor returns another object, so `bumpMember`'s dispatch is SC9012 like `extends Swap` (before: certified through `Holder`). Owners: `getter_reads` in `property_gets.rs`; `reactive_source_uncaptured` in `upstream_compat/shared_reactivity.rs`; `class_instance_is_exact` in `indexes/callees.rs`, `class_chain_prototype_written` in `indexes/class_prototype.rs`. Stub: `argument-sensitive-reads`'.
