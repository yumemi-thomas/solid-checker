# action-in-owned-scope-walk

**Claim (ADR 0973, the second re-check of #231).** What a call runs comes from where its value was made, and the walk that finds that is exact where it follows and says so where it stops (`package-may-call-action:origin-limit`). The cases are the second re-check's 18 programs that Chrome (rc.21) throws on and #231 certified, each with a twin that must stay silent; the same programs run in the pattern lane (`scripts/fuzz/patterns/pkgaction`, one directory each).

- **A package overloads what the library declares** (B1): `OverloadGlobal` (`setTimeout(cb, "fz")` with `declare global { function setTimeout(cb, fz: "fz") }` in `fz-aug2`: every declaration of a global must be the library's for it to be the host's), `ConstructorOverload` (`new Float32Array("fz", cb)`: the construct signature the compiler resolves is `fz-ctor`'s), `WindowVoid` (`window.fzHook()` with `fzHook: VoidFunction`: the property is declared by the package, whatever type it has). `HostCalls` stays silent.
- **A `Proxy` is not a fresh host object** (B2): `ProxyCall`, `ProxyStored` (`new Proxy(makeMap(), {})`: the proxy answers for its target, `Map.prototype.forEach` replaced by the package). `ProxyOfProject` stays silent.
- **A project module's namespace** (B3, S1): `NamespaceAlias` (`const nsAlias = re`), `NamespaceDestructured` (`const { reRun } = re`), `NamespaceNested` (`export * as ns from "./re"`, `outer.ns.reRun`) and `NamespaceMade` (`re.stored()`, `export const stored = makeVoid()`): the export is followed through the project's own barrels to the package's. `NamespaceLocal` stays silent.
- **JavaScript nobody reads** (B4): `ShimBarrel` (`export { vendorStep } from "./step.vendor.js"` behind a wildcard shim, read through `re-shim.ts`) and `ShimQuery` (`./step.vendor.js?fz`: the bundler serves the file whatever the query says).
- **Values the walk follows** (S1): `Conditional` (`flag ? () => {} : makeVoid()`), `Parameter` (`id(makeVoid())`), `Method` (`box.mk()`), `Field` (`holder.f`, a class field), `NestedArray` (`[[makeVoid()]]`), `AssignedStd` (`Object.assign({}, listener)` carries the package's `listener`) and `ArrayFrom` (`Array.from([runStep])[0]`, the row at the call). `ProjectValues` stays silent.
- **A limit is a site** (S1): `ArrayLimit` (an array literal of 257 elements: the walk reads 256) and `DepthLimit` (a chain of 60 `const` aliases: the walk follows 48) are `origin-limit`, `DepthWithin` (4 aliases) is the package's own row. `exactArray[255]()` (256 elements, all the project's) is silent.

Not followed (`docs/open-work.md`): a builtin prototype a package extends without declaring it (`Float32Array.prototype.reverse = …`, pattern `patch-f32-undeclared`), a host call that carries an argument but is not in the table (`Object.entries`, `Promise.resolve`), a container's stored value (`new Map([[k, run]]).get(k)`).

`node_modules/fz-*` are **not** published bytes: each is written for this fixture or its pattern programs. `node_modules/solid-js` and `@solidjs/*` are the manifests of `action-in-owned-scope-unread-packages`; `.solid-checker/runtime.json` closes the program boundary.
