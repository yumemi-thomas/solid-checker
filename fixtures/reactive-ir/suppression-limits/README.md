# suppression-limits

Claim (ADR 0387): a comment suppresses only what it names, on the line it covers, as ESLint reads it. Every component holds one untracked read (SC1001), and every one stays reported: another plugin's rule names, another checker rule, a comment that is not on the line before, an upstream name with no checker rule (`solid/no-single-arg-create-effect`, silent), an unprefixed `eslint-disable` name, a `//` comment spelling the block form, a `-line` comment spanning two lines, and space-separated names (one unknown name, SC9016). The bare `eslint-disable-next-line` before an uncertifiable SC1007 leaves it in place: a comment removes violations, never obligations.
