# impostor-withheld-mutation

ADR 0876: a mutator a reached patch withholds stays a possible mutation. `Object.assign(camera, clone(saved))` writes
keys no fact names, so it is a wildcard on every transported member, withheld or not: `nav.multitouch()` keeps its
`handed-member-dispatch` row. With the call read as "no mutation" transport claimed an exact target and the row went.

`rotate.bind(this)(1)`: a withheld `bind` keeps the `handed-member-dispatch` row a resolved one has.

No row here is a violation.
