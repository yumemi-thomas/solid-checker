# ending-by-code-other-rule-crediting

The negative twin of `ending-by-code-other-rule` (batch 11, slice 4; ADR 0968): the sites whose own rule's finding stands. `OwnRead` is an untracked read in a component body, answered by SC1001's violation; `OwnWrite` is a write in a memo, answered by SC2001's violation. The finding of the rule that claims a site's code ends the site for that code, so no `*-unaccounted` row stands beside either: the two violations are all the program reports (the same sites with another rule's row alone at the span are the positive fixture's).
