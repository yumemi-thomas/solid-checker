# A tracked callback that may never run

Written (ADR 0244) to pin that a contract stating a callback runs tracked under an owner the export creates, possibly zero times (`createLazyMemo`'s calc), makes an accessor read in it not an untracked read, while untracked, mixed or open slots, wrappers and escapes stay uncertifiable. Package contracts are removed (ADR 0312). Today every component is reported alike: the `source()` read in the callback given to `lazyTracked`, `lazyUntracked`, `lazyMixed`, `lazyOpen` or `returnedCalc` is an `SC1001` `strict-read-untracked` uncertifiable result (`Correct`, `Misuse`, all three in `MustRemainUncertifiable`, `NestedEscape`, `OptionalWrite`, `Shadowed` with a local function, `NamespaceCorrect`, two frames in `UnsupportedFrames`, `ReturnedCallbackEscape`), plus the SC9014 notice for the rc.0 stub. The clean/uncertifiable split is no longer pinned. The `solid-reactivity.json` beside the stub is inert.
