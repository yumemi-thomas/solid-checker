# write-scope-roots-rc3

Where a root is the ambient owner of a write or action call (SC2001, SC2002; dev build only): a component body is a root in dev, so on rc.1-rc.8 (store setters exempt roots) a store setter in a body is legal while signal setters throw; `flush(fn)` keeps the caller's owner; an action call in a root body throws on every release; a function passed to `createRoot` by name is the root body. An `addEventListener` listener's calls are uncertifiable (a synchronous dispatch could run it in the root), and so is the rc.3-exempt store setter in `init`, whose role the by-name root does not place. Twin: `write-scope-roots-rc9`. Stubs are byte-for-byte from published `@solidjs/signals@2.0.0-rc.3` `dist/types/` (JSDoc dropped) and `solid-js` rc.3.
