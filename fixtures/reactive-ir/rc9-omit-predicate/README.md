# rc9-omit-predicate

`@solidjs/signals@2.0.0-rc.9` adds `omit<T>(props: T, hidden: (key: keyof T & (string | symbol)) => boolean): Partial<T>` (`dist/types/store/utils.d.ts:251`); the predicate runs on every read of the returned view under the reader. The engine does not follow reads back to the call, so predicate code has no execution role and is never a violation: its reads and writes are uncertifiable, and one not proven inert is `SC9012` at the predicate. Key-list `omit` and standard-library-only predicates are silent; forwarding wrappers get `SC9005`. Overloads are byte-faithful to published rc.9; manifests at `2.0.0-rc.9`.
