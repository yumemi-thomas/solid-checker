# dependency-source-window-realm

**Claim (ADR 0295).** Under a declared Window realm (`runtime.json` `"realm": "window"`, browser target, `dep-query` source), a package's `typeof window`/`typeof document` comparison with `"undefined"` is decided when the identifier is the unbound global, and a module-level `var` holding it carries it when every read runs after the initializer, dropping the proxy trap's server branch (the `@tanstack/solid-query` 6.0.0-rc.0 guard): SC1001 by that claim, but today `WindowQuery`, `ClientQuery`, `DocumentQuery` are SC9012 `type-only-source` (ADR 0294; a lost proof, `docs/open-work.md`); written aliases, shadowed `window`, `globalThis.window` and unsafe module orders are SC9012 `dependency-value-unfollowed` (ADR 0822), never silent; `dependency-source-window-undeclared` lacks the realm. `createContext`/`useContext` are byte-faithful to published 2.0.0-rc.13 `types/client/core.d.ts`.
