# action-in-owned-scope-linked-package

**Claim (ADR 0972).** A workspace package linked into `node_modules` (`node_modules/@ws/kernel -> ../../packages/kernel`) is resolved by the compiler to its real directory, so the declarations of its members are in no `node_modules` and read as the project's own. Its built code is no more read than an installed package's: `@ws/kernel`'s `run(cb)` is `action(function* () { cb(); })()`, and a call in a component body or a memo's compute throws `ACTION_CALLED_IN_OWNED_SCOPE`. The backend finds each such link from the project's attested imports (the real directory of the link's package root, which the compiler's own resolved path lies in) and maps the declaration to the link's spelling, where the package's verdict stands (`PackageReachIndex::linked_spelling`).

- **Uncertifiable** (`package-may-call-action:reaches-solid`, never a violation): `KernelBody` and `KernelMemo` call the member `kernel.run` of an object the module made once (the member's declaration is `packages/kernel/index.d.ts`); `KernelMake` calls the import `makeKernel` itself.
- **Silent**: `KernelTimer` and `KernelHandler` (legal action sites), and `CalmBody`: `packages/calm`'s closure names no Solid package, loads nothing by a computed name and reads only the libraries' globals.

`packages/*` are **not** published bytes: each is written for this fixture, a manifest, a declaration file and the module the closure walk reads. `node_modules/solid-js` and `@solidjs/*` are the manifests of `action-in-owned-scope-unread-packages`; `.solid-checker/runtime.json` closes the program boundary. A linked package whose source the program analyzes is project code, read and not assumed (`variants/source` of the unread-packages fixture covers a package read as source).
