# Interprocedural methods in Solid 2

Class, generic parameter dispatch, conditional candidates and ordinary function controls keep source-based read summaries; the unresolved computed target stays uncertifiable. ADR 0320: `GenericCall`/`EquivalentConditionalCall` pass an exported `const`, which is no longer resolved through its initializer, so dispatch is `SC9012` instead of the SC1001 read. ADR 0299: `ObjectCall` reports nothing at its call since `objectReader` escapes into generic helpers and its receiver census does not admit the direct member body.
