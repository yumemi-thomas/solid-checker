after's authored Call is deferred; inspect's Get supplies no invocation edge.
This is a contract-consumer test, not an audit of a real Router. Exact artifact,
export and receipt admission remain mandatory.

compiler EventHandler versus a dead Show, Show/For/Repeat selection versus

never guaranteed delivery or an owner proof.
