# Feasible browser callbacks

Hand-stated twins pin which registrations CAN run in a browser (ADR 0270; never guaranteed delivery or an owner proof): prop invocation, event handlers, `Show`/`For` selection, effects, timers vs exact cancellation, listeners vs matching removal. The Solid stub has no admitted browser runtime artifact, so `host-cases.json` expects baseline for every registration (explicit browser is the control). Signatures are copied from published rc.13 declarations (`standard-runtime-configuration`).
