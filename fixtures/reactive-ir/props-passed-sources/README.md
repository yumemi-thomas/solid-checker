# A call of a prop's value calls what the call sites pass

A prop every caller passes as an exact identifier is static to read (ADR 0216), but calling its value calls that identifier's source. Pass 10 now records, per prop, the exact sources the visible JSX sites pass (ADR 0509), and a call `props.name(…)` (or a destructured `name(…)`) on the exact props parameter reads, writes or acts with each source's row: `Member` and `Destructured` are violations where they were certified clean (fuzzer sources `prop`, `prop-destructured`). `Handler` stays legal; `Optimistic` passes `createOptimistic`'s setter and stays silent. `Wrapped`'s value is an arrow, which this does not follow: the call is uncertifiable (`closed-parameter-member-dispatch`), never certified. Stub: as `transported-setters-actions`.
