# Single-call parameter transport

One exact direct call to an unexported function supplies an unwritten plain parameter with an exact transported object or returned provider array, sharing the receiver census; body/apply and pre-await calls keep the consumer's role and tracked consumers stay non-violating. Second calls, exports, aliases/escapes, reassignment, default/rest parameters, spreads, `arguments` and escapes refuse the channel; ADR 0273's stability veto applies. Declarations copy the published rc.13 scaffold unchanged.
