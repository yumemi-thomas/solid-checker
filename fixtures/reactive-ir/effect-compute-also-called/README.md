# effect-compute-also-called

**Claim (ADR 1130).** A store read in a function named by its binding as an effect's compute is silent at that tracked position (`local_access` `discover_member.named-at-tracked-position`) only when no direct call of the function runs where an untracked read reports or where nothing places it (`named_calls_report`, through every binding, ADR 1127). The summaries carry the read to no row at such a call in an action step an apply runs, so there the read is SC1001 uncertifiable (`function-run-unplaced`), never a silent clean.

Uncertifiable: `ActionArrow`, `ActionNamed`. Clean: `ActionComputeOnly`. `BodyCalled`: a violation at the read (ADR 1166, the body's call runs it; it was uncertifiable) and at the call. Main left `ActionArrow` and `ActionNamed` clean. Chrome (`runtime-oracle/effect-compute-also-called`): STRICT_READ_UNTRACKED at the three reads, NO_OWNER_EFFECT at the three action-step creations (SC4001 violations), quiet at `ActionComputeOnly`'s read. Stub: `action-in-owned-scope-getters`'s.
