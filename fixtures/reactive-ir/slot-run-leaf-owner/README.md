# Primitive callbacks inside a leaf owner

ADR 0944. `untrack`, `latest`, `isPending`, `flush(fn)` and `runWithOwner(owner, fn)` run their callback on the stack of their call, so a cleanup or a primitive created in it is the leaf owner's child (`@solidjs/signals@2.0.0-rc.21` `dist/dev-shared.js:5842`, `:6740`, `dist/dev.js:1654`, `:1699`; Chrome: CLEANUP_IN_FORBIDDEN_SCOPE and PRIMITIVE_IN_FORBIDDEN_SCOPE at each positive). `untrack` and `runWithOwner` clear tracking, so `resolve` there creates a root (SC3001, not SC2004); `isPending` catches a plain throw but not the diagnostic before one. Silent: `runWithOwner(null)` and a component's owner (no leaf is current), a deferred callback, a caught plain throw, an accessor handed to `latest`, `createRoot` (refused at its own call), a function that only shares a primitive's name. Uncertifiable: an alias, a callback the walk cannot read, an owner the code reassigns.
