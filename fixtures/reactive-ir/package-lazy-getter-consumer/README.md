# Lazy per-key getter consumer

Written (ADR 0282) to pin a hand-stated contract for lazy per-key getters (`makeSize`, `makeStatic`): `TrackedJsx`, `MemoRead`, `StaticLiteral` and the other clean cases would carry no lazy dispatch finding, and `UnprimedRead`, `PrimedRead`, `ComputedKey`, `DeferredAlias`, `Escaped`, `MutatedBinding`, `RetainedSetter`, `ClearedUntrack`, `wrapSize` and `GenericInput` one `reactive-dispatch-unresolved` each. Package contracts are removed (ADR 0312). Today the snapshot holds only the SC9014 notice for the rc.0 stub: every component is silent, so the clean/obligation split is not pinned. `expected-claims.json` (`observed: false`) still lists the old claims and is not read by the checker. The `solid-reactivity.json` beside the stub is inert; synthetic declarations.
