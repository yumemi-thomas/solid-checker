# package-action-step

**Claim (ADR 0961).** A generator handed to a function of a dependency analyzed as source, whose source passes it to `action` (`runAction(cb) { return action(cb); }`), is the step body of an action, though the project never names `action`. `flush` throws inside a step (`[FLUSH_IN_ACTION]`, Chrome, rc.21), and no walk of the project proves the generator to be, or not to be, a step body, so the flush is an uncertifiable row of SC2006 (`function-run-unplaced`), never silence (research-b11 `b11-628-dep-action`; W's `ae-package` cells). The twin `package-action-step-plain` hands the generator to `runPlain(cb) { return cb; }`: no `action` is named anywhere, a handler steps it, and nothing is reported. Package `fz-act` is a synthetic package of these fixtures.
