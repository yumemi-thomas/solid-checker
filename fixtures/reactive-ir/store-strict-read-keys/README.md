# store-strict-read-keys

**Claim (ADR 0293).** A store Get warns `STRICT_READ_UNTRACKED` only for a string key other than `"then"` (rc.9/rc.13 `@solidjs/signals` store trap); own function members are ordinary keys. The head Get of a chain decides: a `then` head is withheld only when the store's literal proves it runs nothing; symbol/dynamic keys, or a `then` head plus another Get, are `SC9012`, never violations. Data/function members and nested chains are violations; destructuring is SC1003. Stubs from `returned-store-proxy` (published rc.13); `tsc` clean against real rc.13 with `skipLibCheck: false`.
