# returned-store-source

**Claim.** A runtime source identity returned from one exact project function: every normal completion returns the same unwritten binding initialized directly by a dialect source primitive in that invocation; caller bindings are distinct identities (SC1001 for same-file/cross-file/namespace hooks, single-binding conditional returns and wrappers); different bindings, plain alternatives, fallthrough, generators, written/escaped roots, calls, loops and reassigned functions are refused. Stubs are byte copies from `prop-head-get`.
