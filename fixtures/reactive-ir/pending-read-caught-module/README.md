# pending-read-caught-module

Claim (ADR 0855): while a module evaluates (module scope, or a function `render` runs, `named_mount_root_role`) no strict-read window is open, so a pending async read emits nothing and throws a plain `NotReadyError` (rc.21, Chrome). A `catch` on the evaluating stack swallows it, and Chrome is silent: `App.tsx`'s `Caught` and `Inline` (a catch elsewhere in the same module may be on the stack) are `SC5001` uncertifiable, `async-read-caught` (both were violations). Kept: `uncaught.tsx`, no catch in the module, a violation (the module throws); `Body`, a component body, emits `PENDING_ASYNC_UNTRACKED_READ` before it throws, caught or not: a violation. Stubs: rc.21's `solid-js`, `@solidjs/signals` and `@solidjs/web` versions; `solid-js.d.ts` as strict as the published typings for what it calls.
