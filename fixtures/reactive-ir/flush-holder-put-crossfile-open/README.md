# flush-holder-put-crossfile-open

The programs `n1-*` and `twin-*` of `flush-holder-put-crossfile` under `--program-boundary open` (ADR 0980): an exported function may be entered by code this build cannot see, so a store through its parameter has no caller list and is handed, whether or not the package step reads the member. Both flushes keep their three uncertifiable rows (SC2006, SC2008, SC3001) and an SC2003 row at the export, as on main; nothing is certified and nothing is a violation. The closed twin of the same text is silent.
