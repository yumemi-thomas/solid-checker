# action-step-window

ADR 0547: rc.17's action `step` (`@solidjs/signals@2.0.0-rc.17` `dist/dev.js:1573-1600`) sets the action depth and clears the effect-callback marker, but leaves `strictRead` and `tracking` as the invoking stack had them; a plain-value `yield` resumes on the same stack (`:1637`), a yielded promise from a microtask. Fable's precision report (2026-11-02, probes R11, R13, R19) measured a body read warning STRICT_READ_UNTRACKED "an effect callback" when an effect apply or a `createReaction` callback calls the action, and silence from a handler, an effect's `error` arm, an owned `onSettled` and a `createTrackedEffect`. FromApply, PlainYield's read after `yield 1` and FromReaction are violations; PlainYield's read after `yield Promise.resolve()`, SilentCallers and HandlerValue (the action as the handler itself) stay silent. MixedCallers (an apply and a handler) is an obligation: the read's run is proven only when every call of the action is. Escaped (the action stored in an object) is an obligation.

The stub reduces the published rc.17 declarations; `@solidjs/signals` is pinned to rc.17 for the release key. The complete source also type-checks against published solid-js rc.17 with strict ES2022 settings. Package bytes are not copied here.
