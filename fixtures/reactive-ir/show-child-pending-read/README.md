# show-child-pending-read

Claim (ADR 0836): a read in a closure handed on from a control-flow child callback with a parameter (`<Show when={1}>{(_u) => { hc1(() => { pending(); }); … }}</Show>`) is not rendered in a tracked insert: the only JSX around it is the element whose child the callback is. `Forwarded` was uncertifiable for the pending rules, never the SC5003 violation it was (rc.21 in Chrome: PENDING_ASYNC_UNTRACKED_READ only; W's `flow-show` forward-2/13, 12 false positives confirmed by Part 13); since ADR 0931 its forward runs in place, SC5001's violation like `InChild`'s. No mount here (ADR 0836's build gave `mount-unresolved`); the grid ids hold its `render()` case. Stubs as in `flow-iife-tracked`.
