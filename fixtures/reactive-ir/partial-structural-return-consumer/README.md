# Partial structural return consumer

Written (ADR 0177) to pin contracts whose returned container lists members without closing the enumeration (`[accessor, unknown]`, `{ value: accessor, stop: unknown }`): `BadTupleRead` and `BadObjectRead` would be violations, good reads and handler uses clean, `unknown` members and escaped returns `reactive-dispatch-unresolved`. Package contracts are removed (ADR 0312). Today the snapshot holds only an SC9014 notice for the `solid-js` stub: no component, including `BadTupleRead` and `BadObjectRead`, is reported, because the stub package declares no `solid-js` peer dependency and nothing describes its returned members. The fixture no longer pins structural-return behavior. The `solid-reactivity.json` beside the stub is inert; manifest bytes are `fixed-structural-return-consumer`'s.
