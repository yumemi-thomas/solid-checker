# A consumer of non-call callback protocols

Written to pin that a contract listing non-call protocol items for an argument (`get`, `coerce`) leaves nothing open, that `access` is uncertifiable in a body and clean in JSX and handlers, `compare` clean, spreads, shadows and wrappers no read, and `accessAlways` (fixture-only `min: 1`) a body violation. Package contracts are removed (ADR 0312). Today the snapshot gives `SC9011` `reactive-source-uncaptured` (uncertifiable) at the `count` accessor passed to the package in `Counter` (four sites), `CounterOpen`, `Handler`, `NamespaceRead` and `GuaranteedRead` (two); `Spread`, `WrapperRead` and `Shadowed` are silent. The protocol distinctions are no longer pinned. The snapshot also holds the SC9014 notice for the rc.0 stub. `index.d.ts` declares `access`/`compare` as `@solid-primitives/utils@7.0.0-next.4` does. The `solid-reactivity.json` beside the stub is inert.
