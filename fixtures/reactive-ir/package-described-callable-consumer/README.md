# A consumer of described callables

Written (ADR 0145/0146) to pin that a contract whose closed `returns` hands back a described callable projects its claims onto the returned value's call: `createIdGenerator`'s reads nothing and is clean (`createIdGeneratorOpen` raises `SC9005`), `createCounter`'s is an accessor (`SC1001` in a body, clean in JSX). Package contracts are removed (ADR 0312). Today the snapshot holds only the SC9014 notice for the rc.0 stub: `Ids`, `IdsOpen`, `UntrackedCount` and `TrackedCount` are all silent, because the stub package declares no `solid-js` peer dependency and nothing describes what the returned functions do. The fixture pins no described-callable behavior. `index.d.ts` declares `createIdGenerator` as `@solid-primitives/utils@7.0.0-next.4` does (`() => () => string`). The `solid-reactivity.json` beside the stub is inert.
