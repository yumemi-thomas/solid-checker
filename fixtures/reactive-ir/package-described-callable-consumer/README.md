# A consumer of described callables

ADR 0145/0146: an accepted contract whose closed `returns` hands back a described callable (a callable plus what one invocation does) leaves nothing open and projects the nested claims onto the returned value's call site: a callable reading nothing is clean (open `returns` raise `SC9005`), one reading an owned signal is an accessor (`SC1001` in a body, clean in JSX). Ships `.solid-checker/authorize-contract.json`; `index.d.ts` declares `createIdGenerator` as `@solid-primitives/utils@7.0.0-next.4` does (`() => () => string`); manifest from `package-member-returns-consumer`.
