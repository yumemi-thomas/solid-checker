# Whole returned callable consumer

Hand-stated contract closing each factory's returns independently of the returned function's graph (`createTicker`: `running` plus an effectful `clear` member; `createPanel`: a function with no graph); no function is inferred to be an accessor and callable/unknown members keep ADR 0234 obligations: body calls, `clear` and reactive members are SC1001; closures, `onClick` values and discards clean; no-graph, opaque, escaped, aliased, stored, exported, JSX-attribute, `let` and mutated forms `reactive-dispatch-unresolved`. Manifest, authorization and stub copy `package-effectful-member-consumer`; declarations are synthetic.
