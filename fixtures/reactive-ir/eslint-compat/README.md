# The eslint-era surface, answered by the Solid 2.0 catalog

Ported off its 1.x stub: findings keep the same claim and span under a rule name that lost its `v1/` prefix, except where the dialect answers differently about the same bytes. `jsx-no-duplicate-props` SC8003 at 1618 is not reported on 2.0 (`upstream_compat/syntax.rs` folds props into DOM template slots only when `folds_dom_slots` is true, and that is hardcoded `false`). `reactive-handler-frozen` SC1007 is not reported on `on-foo={0x10}` (3551) or `on-foo={-1}`: the pinned rc.17 compiler lowers only `on` + an uppercase letter as a listener (`Dialect::compiler_lowers_event_attribute`), so these are plain attributes. The `attr:title` slot pair and the `attr:`/`bool:`/`on:`/`oncapture:`/`use:` intrinsic cases were removed because rc.17's compiler rejects those namespaces on intrinsic elements; `<Panel on:click>` on a component still compiles. This is the only pin for these mechanics.
