# leaf-visited-entry-namespace

**Claim (ADR 0961).** The twice-entered walk of `leaf-visited-entry`, with every primitive spelled through the namespace import: `make(true); make(false)` with `S.createMemo` in the helper, and `S.isPending(flushes); flushes()`. Violations at the second entry (SC3001); the tolerant-only twins are clean for SC3001. Until ADR 1095 a namespace import named every export of `solid-js`, `action` among them, and the flush in a function handed by name to `S.isPending` was an uncertifiable row of SC2006 and SC2008 (`function-run-unplaced`, ADR 0708). Every reference to `S` here is a static member, so the program names only `createSignal`, `createMemo`, `flush`, `createTrackedEffect` and `isPending`: no primitive steps an action or defers an apply, and the flush has neither row.
