# read-in-place-layers

**Claim (ADR 0469).** A read in a function layer that runs in place (an IIFE, an inline `forEach` callback, a helper that calls its callback in its own body) runs on the stack of the layer's call, so it is placed as a read written at that call. In a created root's body, a `runWithOwner` callback or an effect apply the strict-read window is open there. Violations (rc.17 warns `STRICT_READ_UNTRACKED`, fast path): `RootIife`, `RootForEach`, `RootHelper`, `RootHelperAlsoKept` (one run of a callback the helper also keeps is in place), `RootNamespaceIife`, `RootAsyncIifeBeforeAwait`, `OwnerIife`, `ApplyIife`, `ApplyForEach`, `ApplyHelper`, `ApplyNestedLayers`, and the equivalence pair `ApplySetterOfReadIife` (`setK(r())` in an IIFE). `RootDirect` is the direct control. Before, every layer form was certified clean: the root and apply arms placed only a read written directly in the callback, and the enclosing callback's span answered the silent deferred role.

Legal (rc.17 silent): a nearer tracked computation (`RootMemoIife`), `untrack` (`RootUntrackIife`, `ApplyUntrackForEach`), a fresh stack (`ApplyTimer`), past an await (`RootAsyncIifeAfterAwait`), a function the root returns and a handler calls (`RootReturnedLayer`), a helper that hands its callback back (`RootHelperNeverCalls`), a layer in JSX, whose insert computation tracks it (`RootJsxIife`).

Uncertifiable: a layer's default value, which runs only when its call omits the argument (ADR 0454; `RootIifeDefault`), and a read an await only may precede (`RootIifeMaybeAwait`); rc.17 warns in both. `ShadowedRoot` (a local `createRoot`, rc.17 silent) was uncertifiable before and stays so. Stub: rc.17 shapes (copied from `write-callback-by-name`).
