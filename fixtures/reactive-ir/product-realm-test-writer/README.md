# product-realm-test-writer

**Claim (ADR 1145).** A site in a file the product's real entries load is judged against the prototype writers those entries load, not against writers only a test loads. `index.html` names one module script, `/main.tsx`; the import closure of `main.tsx` is `main.tsx` and `App.tsx`, and it loads no package. `vite.config.ts` (no plugin; vitest's `test.setupFiles`) is the whole bundler configuration. `setup.ts`, the vitest setup file, imports `fz-prealm-named` (writes `Float32Array.prototype.reverse`) and `fz-prealm-any` (writes `Float32Array.prototype[Symbol.iterator]`, a key the scan does not decide). The page loads neither.

- **Cleared (a typed silence, no row)**: the seven SC2002 sites of `App.tsx` (`CalledDirectly`, `CalledOnAny`, `TemplateSubstitution`, `Unwritten`). Each ends in `package_action_calls.package_action_calls.product-realm` and is named in the proof log. Dropping the silence (`SOLID_CHECKER_IR_ABLATE_SILENCE=package_action_calls.package_action_calls.product-realm`) gives back the seven rows every writer of the program gave them.
- **Kept (an uncertifiable SC2002 row each)**: the test's own sites in `app.test.tsx`, which imports `App.tsx`: a test is not the product, so it keeps every writer, and the product's judgment does not depend on who imports the product. `setup.ts`'s two imports keep their `package-finding-at-entry` rows.
- **Kept, unchanged**: `App.tsx:3`'s SC9012 `standard-member-impostor` row. It is another consumer of the writer set (`indexes/callees.rs`), still judged against every writer (`docs/open-work.md`, ADR 1145).

Twins, each its own project: cleared `-test-writer`, `-package-exports` (a package's entries), `-tsconfig-paths-applied`, `-asset-query`; kept `-product-writer`, `-dev-client`, `-dev-client-production`, `-second-page`, `-plugin-name`, `-plugin-unpinned`, `-plugin-missing`, `-config-writer`, `-computed-load`, `-js-sibling`, `-subpath-imports`, `-custom-conditions`, `-tsconfig-paths`, `-url-script`, `-other-vite-config`, `-vite-script-config`.

`node_modules/fz-*` and `node_modules/vite*` are **not** published bytes: each is written for this fixture. `node_modules/solid-js` and `@solidjs/*` are the manifests of `action-in-owned-scope-prototype-writes`; `.solid-checker/runtime.json` selects `browser`, `development`, `csr`. `vite.config.ts` is not part of the program (`tsconfig.json` excludes it); the checker reads it as configuration.
