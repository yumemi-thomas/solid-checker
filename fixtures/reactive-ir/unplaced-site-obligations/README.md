# unplaced-site-obligations

**Claim.** Where no fact places a site, its rule reports an uncertifiable obligation instead of staying silent: a write in a closure a memo only stores, or in an exported helper with no caller (SC2001); a read in a helper called after an `await` in an async memo (SC1002); `until`/`resolve` in an exported helper nothing places (SC2005/SC2004; a helper called once from a memo compute is a violation, ADR 0494); options the syntax cannot read beside an async computation (SC7002); a primitive used as a value (`Reflect.apply(createEffect, …)`, `const effect = createEffect`, `Solid.createEffect`, `[createEffect]`, a conditional, SC9012); a write and read after a `for await` under a branch (SC2001/SC1001); `resolve` in a callback handed to an opaque function (SC2004). Controls stay as they were: the body write, the direct after-await read, the direct `until`/`resolve` in a memo, the literal `sync: true` and the module-scope `createEffect` are violations, and `createEffect.call(…)`/`.bind(…)(…)`, methods of the primitive whose arguments fill other slots, are SC9012 rather than primitive calls; an intrinsic event handler, an effect apply, a helper called before the await or reading nothing, a source read before the first suspension, an action step, `onSettled`, proven-absent or false `sync`, a synchronous computation, a type query and a re-export report nothing. Stub declarations are copied from published rc.13 (see `solid-js.d.ts`); `node_modules` pins the rc.13 triple, which `until` needs.
