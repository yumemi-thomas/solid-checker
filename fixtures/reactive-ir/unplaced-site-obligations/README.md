# unplaced-site-obligations

**Claim.** Where no fact places a site, its rule reports an uncertifiable obligation instead of staying silent: a write in a closure a memo only stores, or in an exported helper with no caller (SC2001); a read in a helper called after an `await` in an async memo (SC1002); `until`/`resolve` in an exported helper nothing places (SC2005/SC2004; a helper called once from a memo compute is a violation, ADR 0494); options the syntax cannot read beside an async computation (SC7002); a primitive used as a value (`Reflect.apply(createEffect, …)`, an exported `Solid.createEffect`, `[createEffect]`, a conditional, SC9012; `const effect = createEffect` names the primitive since ADR 0901, so `effect(…)` at module scope is SC4001's violation, as the control is); a read after a `for await` under a branch (SC1001; the write beside it takes its function's only entry, a module-scope render with no owner, legal on both paths: ADR 0610); `resolve` in a callback handed to an opaque function (SC2004). Controls stay as they were: the body write, the direct after-await read, the direct `until`/`resolve` in a memo, the literal `sync: true` and the module-scope `createEffect` are violations, and `createEffect.call(…)`/`.bind(…)(…)`, methods of the primitive whose arguments fill other slots, are SC9012 rather than primitive calls, with `createEffect`'s SC6002 and SC7002 uncertifiable at the callee (ADR 0902: an attribution through the operand, never a proof); an intrinsic event handler, an effect apply, a helper called before the await or reading nothing, a source read before the first suspension, an action step, `onSettled`, proven-absent or false `sync`, a synchronous computation, a type query and a re-export report nothing. Stub declarations are copied from published rc.13 (see `solid-js.d.ts`); `node_modules` pins the rc.13 triple, which `until` needs.
