# unplaced-site-obligations

**Claim.** A site no fact places is an uncertifiable obligation, never silence: a write in a closure a memo stores, and a write and read in an exported helper with no caller (SC2001, SC1001, ADR 0934); a read in a helper called after an `await` in an async memo (SC1002); `until`/`resolve` in an exported helper (SC2005/SC2004; called once from a memo compute it is a violation, ADR 0494); options the syntax cannot read beside an async computation (SC7002); a primitive used as a value (`Reflect.apply(createEffect, …)`, an exported `Solid.createEffect`, `[createEffect]`, a conditional: SC9012; `const effect = createEffect` names it since ADR 0901, so `effect(…)` at module scope is SC4001's violation); a read after a `for await` under a branch (SC1001; the write beside it: ADR 0610); `resolve` in a callback handed to an opaque function (SC2004). Controls: the body write, the direct after-await read, the direct `until`/`resolve` in a memo, literal `sync: true` and the module-scope `createEffect` are violations; `createEffect.call(…)`/`.bind(…)(…)` are SC9012 with SC6002/SC7002 uncertifiable at the callee (ADR 0902); an event handler, an effect apply, a helper called before the await or reading nothing, a read before the first suspension, an action step, `onSettled`, absent or false `sync`, a synchronous computation, a type query and a re-export report nothing. Stubs: published rc.13; `node_modules` pins the triple `until` needs.
