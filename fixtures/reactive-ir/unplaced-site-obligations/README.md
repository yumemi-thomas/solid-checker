# unplaced-site-obligations

**Claim.** Where no fact places a site, its rule reports an uncertifiable obligation instead of staying silent: a write in a closure a memo only stores, or in an exported helper with no caller (SC2001); a write and read after a `for await` under a branch (SC2001/SC1001). Controls stay as they were: the body write is a violation; an intrinsic event handler and an effect apply report nothing. Stub declarations are copied from published rc.13 (see `solid-js.d.ts`); `node_modules` pins the rc.13 triple.
