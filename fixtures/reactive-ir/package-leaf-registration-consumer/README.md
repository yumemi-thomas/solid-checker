# A package registration inside a leaf owner

ADR 0179: an accepted contract stating an export registers a cleanup/computation on its caller's owner on every call makes calling it in a leaf owner a forbidden operation: `listen()`/`startTickerAlways()` in `createTrackedEffect` or `onSettled` are `SC3001` violations; `startTicker()` (`min: 0`) uncertifiable (ADR 0231); `startTickerSilent()` and component bodies clean; a microtask-wrapped `listen()` is `SC4001`. Contract is `package-computation-consumer`'s plus `listen`; manifest from that fixture; rc.9 `solid-js` stub verbatim from `fp-owner-leaf-helper-after-await`.
