# A package registration inside a leaf owner

Written (ADR 0179, 0231) to pin that an export stating a cleanup or computation on the caller's owner is an `SC3001` violation in a leaf owner (`createTrackedEffect`, `onSettled`), `SC4001` when microtask-wrapped, uncertifiable at `min: 0` and clean when silent. That came from a package contract, removed with ADR 0312. Today the five calls directly in a leaf callback (`CleanupInTrackedEffect`, `ComputationInTrackedEffect`, `CleanupInSettled`, `MaybeInTrackedEffect`, `SilentInTrackedEffect`) each give `SC9012` `reactive-dispatch-unresolved` (uncertifiable), including the formerly clean one; `DeferredInTrackedEffect` and `InComponentBody` are silent. The snapshot also holds the SC9014 notice for the rc.0 stub. The rc.9 `solid-js` stub is copied from `fp-owner-leaf-helper-after-await`. The `solid-reactivity.json` beside the stub is inert.
