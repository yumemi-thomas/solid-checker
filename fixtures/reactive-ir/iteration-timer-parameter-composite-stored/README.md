# iteration-timer-parameter-composite-stored

**Claim (ADR 1056), the stored twin.** `(slot = afterNextPaint)(() => …)` also stores the function in `slot`, and `later` calls `slot` with a function that reads `this`. That is an entry no call of `afterNextPaint` shows, so `resume` may be any function, the census keeps the window handed, and `set(2)` is uncertifiable (`tuple-iteration-written`). Chrome reports the write (oracle case, covered-uncertifiable). Before ADR 1056 the census read the assignment through ADR 0515's peel as a direct call and proved it.
