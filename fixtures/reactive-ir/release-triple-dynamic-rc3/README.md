# release-triple-dynamic-rc3

On rc.3 `dynamic(source, { static: true })` gets the default model: `@solidjs/web@2.0.0-rc.3` declares `dynamic(source)` (`types/index.d.ts:81`; two-argument calls are TS2554 against the byte-faithful stub and real rc.3) and no build before rc.9 reads `options?.static`. Each static call behaves as its one-argument twin. The snapshot shows it: both writes (`StaticWrite`, `DefaultWrite`) are `SC2001` inside the memo's tracked compute, neither effect inside a `dynamic` source reports `SC4001` (the memo is their owner), and the one `SC4001` is the `untrack` reference. It also carries the `SC9014` release notice: the rc.3 triple is not the audited release.
