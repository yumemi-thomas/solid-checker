# async-creation-pass

**Claim (ADR 0570).** A pending async read (SC5001, SC5003) is proven only where the read runs in the synchronous pass that created its source (`owners::read_in_creation_pass`): the reader's own body or a hook it calls, or a reader its creator mounts on its own stack (intrinsic children, a context provider, `<Show when={true}>`, a literal `<For>` row, a literal-fallback `<Loading>`), or, for a module-scope memo, a reader a module-scope `render` reaches that way. A reader mounted later (`<Show when={on()}>`, `<Switch>`/`<Match>`, `<For each={xs()}>`, a project component's children) meets a parent's or module memo settled, where rc.17 warns only `STRICT_READ_UNTRACKED`: the finding is uncertifiable (`AsyncRead::creation_pass_unproven`), never a violation.

Violations (`FirstParent`, rendered by `main.tsx`): SC5001 in `FirstPropReader` (prop), `FirstCtxReader` (context, through `createRoot` and the wrapper `h1`), `FirstModReader` (module memo), `ShowTrueReader` (`<Show when={true}>`, in `createRoot`), `FirstSettledReader` (`onSettled`, warning), `NamespaceTrueReader` (`<S.Show when={true}>`); and `HookReader` in `LaterParent` (its own hook creates the memo in its body, so even a later mount meets it pending).

Uncertifiable, never a violation (each a violation on 719b0e49a; Chrome-confirmed shapes in the fuzzer's lg-pairs `show-later` × `async-prop`/`async-context`): SC5001 in `LaterPropReader`, `LaterCtxReader`, `LaterModReader`, `LaterSettledReader`, `LaterWrapReader` (context, wrapper `h2`), `ForReader`, `MatchReader`, `NamespaceReader` (`<S.Show when={on()}>`), `PanelReader` (a project component's children), `LookalikeReader` (a project `Show`, shadowed name); SC5003 in `JsxReader`.

Stub: `async-carrier-provably-runs`'s `solid-js.d.ts`, plus rc.17's `Switch`, `Match`, `createContext`, `useContext` and `@solidjs/web`'s `JSX` export; `package.json` makes the program closed (context transport). `tsc --noEmit` clean on the stub and on the published rc.17 packages.
