# An unaudited router release (ADR 0324 refusal)

This project resolves `@solidjs/router` `2.0.0-next.18`, which no one read.
The premise is not applied and the project carries an `SC9014` notice at the
`useParams` import naming the router and the audited release. The declarations
here are `2.0.0-next.26`'s with the `version` field changed: the premise reads
the resolved release only, so the declarations do not matter to the case, and
the fixture claims no fidelity to `next.18`'s bytes.

The copy is the published `2.0.0-next.26` files with only the manifest's version changed to `2.0.0-next.18`.
