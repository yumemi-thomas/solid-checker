# parameter-initializer-after-await

**Claim (ADR 0961, PD; batch-10 addendum 12 group D).** A call written in the own body of an async tracked computation after its await runs the parameter initializers of the function it calls, or of the constructor it constructs, when it omits the argument: they run on the continuation, with no observer, so a source read there warns `UNTRACKED_READ_AFTER_AWAIT` (Chrome, rc.21). The after-await walk read an accessor call written directly in a default and followed no IIFE, closure, destructuring default or constructor's, so the program was certified clean. Where such an initializer holds a call or a member access (a function literal's own invocation reads nothing) and the call omits the argument (none at its index, `undefined`, or a spread that may), the call is an uncertifiable row of SC1002 (`parameter-initializer-unplaced`), never a violation and never silence. A destructuring pattern's defaults run whatever the argument is.

`App.tsx`: `Iife`, `Closure`, `Destructured`, `Constructed` (rows), `UndefinedArgument` (a row: `undefined` runs the default). Silent: `Passed` (the arguments are passed), `BeforeAwait` (a dependency), `NothingToRead` (a constant default and an IIFE that reads nothing). A constructor of a class written in another file is not followed (an open case, the same as a helper in another file whose parameter list the walk does not read). The defaults themselves carry SC1001 uncertifiable rows (`function-run-unplaced`), as before.

**Batch-10 addendum 13: only syntax proves an argument defined.** The call keeps a default from running only when its argument is `null`, a function expression, or a primitive, object or array literal (the standard of `argument_values.rs`: a type says nothing about runtime nullishness). An identifier or any other expression may be `undefined` at run time, so its default may run: `IdentifierArgument` (`const maybe: number | undefined = Math.random() > 2 ? 1 : undefined; iifeDefault(maybe)`), `ConditionalArgument` and `ConstructedArgument` (`new Box(c ? 1 : undefined)`) are rows; Chrome (rc.21) warns at the default's read in each, and 588affbf3 and the first build of this ADR were silent. `DefinedArguments` is silent (`null`, a string, `{}`, `[]`, a template literal, a function expression). The cost is the rows of calls that pass an identifier to a default-bearing parameter after an await, the coarse typed obligation.
