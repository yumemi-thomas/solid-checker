# spread-prop-backing

**Claim.** A call site whose last spread is the enclosing component's own props object (`<Inner {...props} />`) forwards the reactive direction of every parent prop that the element does not set after the spread. `@solidjs/signals@2.0.0-rc.13` `merge` resolves each key lazily from the last source that has it, so `Inner`'s read of such a prop runs the parent's getter. The spread still proves nothing static: the receiving component escapes enumeration as before.

A lone spread into a component that only spreads its props on keeps the getter (`ChainOuter`). Kept uncertifiable: a later attribute or child setting the name (`OverriddenOuter`), a later spread of another object (`LaterSpreadOuter`), a `merge` view (`ViewOuter`), a reassigned props parameter (`ReassignedOuter`), a lone spread into a receiver that deletes the getter (`DeletingOuter`: `createComponent(Child, props)` hands over the object itself, while any other attribute, spread or child makes it a `mergeProps` view whose writes are no-ops), and a parent whose callers pass only literals (`StaticOuter`). `solid-js.d.ts` is copied from `forwarded-prop-backing`.

An element with several sources is a `mergeProps` view only when one source besides the props is provably never falsy (compiler `shared/component.rs` lowers each run of attributes or children to an object literal and a member spread such as `{...props.extra}` to a function source; rc.13 `merge` returns its one non-falsy source itself). Violations: `MemberSpreadOuter`, `AttributeSpreadOuter`, `ChildSpreadOuter`. A bare-identifier second spread (`{...props} {...extra}`, `extra` possibly `undefined`) hands the callee the props object itself, so the receiver is checked like a lone spread: `ExtraDeleteOuter` (`delete props.count`) and `ExtraDefineOuter` (`Object.defineProperty(props, "count", ..)`) stay uncertifiable. Both lowerings (native and `@solidjs/babel-plugin`) are covered: Babel drops a `children` attribute when the element has any raw child (`ChildrenAttrOuter`, uncertifiable; `ChildrenAttrSelfOuter`, a self-closing element keeping it, is a violation), and passes a member spread with a leading `/*@static*/` comment raw (`StaticMemberOuter`, uncertifiable), so any comment in a spread removes it from the never-falsy sources.
