# action-in-owned-scope-global-routes

**Claim (ADR 0973, the reviews of #231: the call side of a global a package writes).** A global a package writes at run time is that package's code where the project calls it, and where the package defines an accessor for it the accessor runs where the project reads it. The project reaches the global object by many routes, and each is the same global as the package side follows (`module_reach.rs`: the names it goes by, `window.self`, `document.defaultView`): the call side resolves every route the same way, and a route it cannot decide is a read of any global.

- **A call of `btoa`, which `fz-rbtoa` replaces** (uncertifiable, `package-may-call-action:reaches-solid`): `window["btoa"]` and `globalThis["btoa"]` (a string-literal key), `const k = "btoa"; window[k]` (a name that only holds a string), `window.self.btoa`, `window.window.btoa`, `document.defaultView!.btoa`, a name the global object is bound to (`const w = window; w.btoa(…)`), a member bound to a name (`const enc = window.btoa`), a destructuring of the global object or of a member that gives it back (`const { btoa: enc } = window`, `const { btoa } = globalThis`, `window.self`), an array element (`[btoa][0](…)`), either operand of a conditional (`(flag ? window : self).btoa`) and a function that returns it (`getWindow().btoa`).
- **A key the program does not spell** (`window[key]("x")`, `void window[key]`): the call may run any global's code, the read any accessor, so each is a site wherever a package that may reach a Solid action writes a global (or defines an accessor) at all.
- **The global object handed to a call** (`reader(window)`, `reader(w)` for a name it is bound to): what the callee reads off it is not followed (the package side calls that an escape), so the call is a site that stands where a throw inside the callee has its project frame (`HandedOn`, `HandedAliased`); `HandedLocal` hands an object the program made and is silent.
- **A read of `devicePixelRatio`, which `fz-racc` defines an accessor for with `Object.defineProperty(window, …, { get })`**: `window.devicePixelRatio`, the bare name, `typeof window.devicePixelRatio`, `window["devicePixelRatio"]`, `const { devicePixelRatio: ratio } = window` (the row stands at the pattern, where the runtime reports the call) and a read through a name the global object is bound to.
- **Silent**: `ClearWriter` (`fz-rclear` writes `atob` and names no Solid package), `UnwrittenName` (`innerWidth` has an accessor only in the clear package, `screenX` is written by none), `DataRead` (`fz-rdata` replaces `unescape` with a data property: reading it runs nothing; a CALL of it is a site, see `action-in-owned-scope-global-writes`) and the two shadowed forms (a parameter or a `const` that is called `window` or `globalThis` is the file's own).

Why an accessor and not any write: a data write cannot run package code on a read, and a writer under a key nothing decides (`vitest`'s `for (const key in config.defines) globalThis[key] = …`) would make every read of `window`, `document` or `console` a site wherever it is installed. The scan records the names a package defines an accessor under on the global object (`defineProperty` with a get or a set or a descriptor it cannot read, `defineProperties`, `__defineGetter__`, a change of the global object's prototype, a writer used where its target is not seen); only those make a read a site.

Chrome (rc.21): the pattern lane's `pkgaction/global-call-*` (every route above) and `global-value-*` throw `ACTION_CALLED_IN_OWNED_SCOPE` at the call or the read.

Not followed (`docs/open-work.md`): the global object kept in a field or an array the walk does not follow, or reached through a DOM object's typed member (`el.ownerDocument.defaultView`); an assignment destructuring (`({ btoa: enc } = window)`) of a call's route (the read is a site, the later call of `enc` is not followed).

`node_modules/fz-*` are **not** published bytes: each is written for this fixture. `node_modules/solid-js` and `@solidjs/*` are the manifests of `action-in-owned-scope-unread-packages`; `.solid-checker/runtime.json` closes the program boundary.
