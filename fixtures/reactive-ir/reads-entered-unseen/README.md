# reads-entered-unseen

ADR 0934: reads in a non-component export of an open program are SC1001 uncertifiable, as its writes are: `bump`, `peek`, `arrow`, `readStore`, `outer`'s closure, `Shaped` (no JSX), `step` (a handler calls it too). Clean: `later` (past an `await`), local and dead helpers. Twin: `-closed`.
