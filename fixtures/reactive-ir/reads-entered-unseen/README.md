# reads-entered-unseen

**Claim (ADR 0934).** A function that is no component and that code the program does not hold may enter (an export of an open program, a namespace hand-out) has no call the summaries hold, so its reads are uncertifiable (SC1001 `function-run-unplaced`), as its writes already were (SC2001): an exported helper with no caller (`bump`, `peek`, `arrow`, a store read in `readStore`), a closure nested in one (`outer`), a capitalized export returning no JSX (`Shaped`, ADR 0445), and an export a local handler also calls (`step`). Chrome (rc.21): each read warns STRICT_READ_UNTRACKED when a component body calls it. Clean: a read past an unconditional `await` (`later`, ADR 0323), a local helper only a handler calls, a helper nothing references, a component's tracked read. Twin: `reads-entered-unseen-closed`, the same code in a closed program (ADR 0203), is clean. Stubs: `rc21-listener-no-dispatch`'s.
