# after-await-promise-unconsumed

**Claim (ADR 1090, G1 residual).** rc.21's dev build raises UNTRACKED_READ_AFTER_AWAIT only for a read whose V8 async stack holds the frame `__solidAsyncCompute_<id>`, the async function that awaits an async computation's returned promise (`@solidjs/signals` `dist/dev-shared.js` `watchAsyncTail`, `attributedFlight`). V8's async frames are the chain of code awaiting the current promise, so a read in a function whose promise nothing consumes cannot be attributed to any computation. The after-await accounting ends such a site (`AfterAwaitSafe::PromiseUnconsumed`, `after_await_accounting/unconsumed.rs`) when the function is a named, current, unexported async function every reference of which is a discarded direct call and the read is past an await the function runs on every run. The program has no direct `eval` (fixture after-await-promise-unconsumed-eval).

Clean: `fire` (a discarded call).

Uncertifiable (fail closed): the two `.then` handlers (no exact fact says the receiver is a native promise; `Kept` is a subclass that keeps its instances), `looped` (its loop reads before the first await), `voided` (`void f()`: the promise is an operand), `stored` (the promise is kept), `exported` (a host may call and await an export, referenced or not), `chained` (the derived promise is returned), and `awaited`, which an async memo awaits: its read is the producers' (Chrome reports UNTRACKED_READ_AFTER_AWAIT there).
