# Inferred host: spa

Hand-stated browser-only document: only the parsed HTML module entry (`index.html` to `src/main.ts`) authorizes the root, and `main.ts` calls the stub package's `startClosed()` at module scope. A package contract once gave that call a mandatory owner requirement its void signature cannot express, so browser admission turned it into an SC4001 violation (`expected-claims.json`, hand-stated and unrun, still says so). Package contracts are removed (ADR 0312): the call is now opaque, the snapshot records status `uncertifiable` with no listed finding, and the admission upgrade is no longer pinned by it. The `*-cases.json` proof inputs (class, nullish, resource, completion, startup; ADR 0270) are read by Rust tests and pin eager vs inert work. Element/JSX declarations are byte-for-byte from `package-captured-lookup-consumer`. The `solid-reactivity.json` beside the stub is inert.
