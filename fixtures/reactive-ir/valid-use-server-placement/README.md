# SC7006: where the directive takes effect

The audited compiler (`@solidjs/compiler@2.0.0-rc.17`, `packages/compiler/src/directives/`) reads a `"use server"` directive only from a module's or function body's prologue and extracts only functions, arrows with block bodies and declarations; the rule reports the placements it ignores or rejects. Positive: a string statement after another statement, in a block, in a loop; a template literal; a directive in an object method, getter, setter, class method or constructor. Negative: the prologue after another directive; function-valued properties and class fields; a directive nested in an extracted server function (ignored by the pass); a directive file with a stray function-level string; a string in expression position. One file per shape, `*.ts`.
