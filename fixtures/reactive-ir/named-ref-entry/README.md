A named function whose only reference is an intrinsic element's `ref={name}` is entered by the ref's application alone (ADR 1160): the entry census counts that reference as the ref position. `RefWrite`'s setter call is silent (main: SC2001 uncertifiable, `function-run-unplaced`); `RefRead`'s read is SC1001's violation, as an inline `ref={() => …}` is. `AlsoCalled` (the function is also called in the body), `Exported` (an importer may call it) and `ComponentRef` (a component's `ref` is a prop the child calls) keep their rows.
