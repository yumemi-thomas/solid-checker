# primitive-identity-scope / meta-use-head

Variant of `primitive-identity-scope` with its own `node_modules`: `@solidjs/meta` is published `@solidjs/meta@1.0.0-next.2` bytes (`package.json`, `dist/index.js`, `dist/index.d.ts`; MIT; `sha512-4aqPczFqDdep4JTAUXfh4nyfq7InbTgimd7NuN6ZWWE29UPv0uR5dyr53yFcf2YgVXjFdX+JGhXtsE0njGL+fA==`), analysed from source. The `solid-js`, `@solidjs/signals` and `@solidjs/web` stubs are the parent fixture's rc.17 stubs plus the declarations meta names (see their headers; `useHead` is `@solidjs/web` `types/client.d.ts:329`).

`@solidjs/meta` defines no primitive. Its `useHead` is `@solidjs/web`'s, imported at `dist/index.js:2`, so it is the primitive through that import, and through the `@solidjs/web` declaration the import resolves to (ADR 0365). `Page` renders `<Head><Title>` and stays silent. `Writes` calls `useHead` with a tag function that writes a signal: `useHead` runs it as an effect's compute (`@solidjs/web@2.0.0-rc.17` `dist/web.dev.js:1546-1554`), so the write is SC2001, a violation only because the callee is exactly `@solidjs/web`'s `useHead`. Without that identity it is an uncertifiable SC2001. `Titled`'s read in a tag function is tracked and silent. `@solidjs/meta@0.29.4` (the 1.x line, also in the rc.17 corpus) declares a `useHead` of its own, which the path rule used to name the primitive and ADR 0365 does not.
