# primitive-identity-scope

Primitive identity is exact (ADR 0365): a declaration is a Solid primitive only as a module-scope `function` or `variable` declaration in a declaration file of an installed copy of one of the dialect's primitive-defining packages (`solid-js`, `@solidjs/signals`, `@solidjs/web`). A same-named binding of another `@solidjs/*` package is that package's own. The path rule this replaces named any declaration under a `solid-js` or `@solidjs` path component after the primitive it was spelled like; on the rc.17 corpus it named `@solidjs/router`'s local `const flush = whenIdle(...)` (`dist/preload.js:139`, `:168`) Solid's `flush` and its `useAction(action)` parameter (`dist/data/action.js:235`) Solid's `action`, and both fed the ADR 0362 flush veto.

`node_modules/@solidjs/fake-tools` is not a published package. It is in the `@solidjs` scope and analysed from source (`.solid-checker/runtime.json`), and it exports `flush`, `createEffect`, `useHead`, `useAction` and `preloadWhenIdle` of its own. The `solid-js`, `@solidjs/signals` and `@solidjs/web` stubs are `primitive-in-effect-callback`'s rc.17 stubs, byte-faithful for the signatures the claims rest on (see their headers).

Base (`App.ts`): the package's `flush(fn)` in a `createRoot` body is not Solid's, so the `createMemo` in the `createEffect` apply is an SC4005 violation; the package's `useHead` runs its tag on the root body's stack (silent). Under the path rule the SC4005 was uncertifiable. The call passes an argument so that its callee is resolved: an argumentless `flush()` of another package is never resolved, and ADR 0362's spelling rule still counts it.

Variants: `package-local-flush` (the router's `whenIdle` local inside the package; violation), `use-action` (the router's `useAction(action)` parameter; violation), `package-effect` (the package's `createEffect` runs its apply on the caller's stack: silent, where the path rule made its `onCleanup` an SC4001 obligation), `solid-flush` (Solid's `flush` in the root body: SC4005 uncertifiable, ADR 0362), `meta-use-head` (published `@solidjs/meta@1.0.0-next.2` from source; its `useHead` is `@solidjs/web`'s, see its README).
