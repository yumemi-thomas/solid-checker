# phase-handed-by-name

ADR 0538: full-6 (2026-11-01) certified clean, or gave another rule, 843 misuse programs that rc.17 fires: a named function handed to a carrier, a member or project code inside a primitive's callback. The effect-phase walk (SC2008 `flush-in-effect-callback`, SC6002 `primitive-in-effect-callback`) now places a run at an inline carrier (`forEach`, a template tag, `Reflect.apply`) and at the calls a project component makes of a callback prop it only ever calls (`props.run()`, a destructured `run()`): ApplyForEach, ApplyTagged, ApplyReflect, PropApply, PropApplyDestructured, MemoForEach and MemoProp are violations. A hand-off nothing places (a project helper's argument, a member's value, an object slot, a method of a nested class) is an obligation anchored at the code around it: ApplyWrapper, ApplyThisMember, ApplyReturnedMember, ApplySlot, PropShared, MemoWrapper. A layer proven to run elsewhere stays silent: ApplyTimeout, ApplyListener, ApplyModuleClass, PropHandler, PropDeferred.

SC2006 `flush-in-action` takes the same placement (actionForEach is a violation, commit 831c70635's carrier case) and the same obligations (actionMember, actionWrapper, actionThisMember); a chain of in-place layers past ADR 0532's bound of 16 is re-asked from where the climb stopped, as an obligation (actionDeep); actionTimeout stays legal. SC3001 `leaf-owner-forbidden-call` follows a template tag written in the leaf callback (TrackedTagged, SettledTagged); SettledTaggedClean stays silent.

The stub reduces the published rc.17 declarations. The complete source also type-checks against published solid-js rc.17 with strict ES2022 settings. Package bytes are not copied here.
