# stored-function-after-await

**Claim (ADR 0964, batch 10b).** A function the program stored where nothing follows it (an array, a map, an object's list, a variable) and invoked through the name it was stored under, after the `await` of an async tracked computation, runs on the continuation: a source it reads is untracked, and Chrome (rc.21) warns `UNTRACKED_READ_AFTER_AWAIT` at it. The call resolves to no function the walk knows, so the program was certified clean for SC1002 beside only SC1001's uncertifiable row at the read (another rule's row covers nothing of the claim). An unresolved invocation after the await is an uncertifiable row of SC1002 (`unresolved-invocation`): never a violation (nothing here proves what was stored or that it reads a source) and never silence.

`App.tsx`: `Foreach`, `Aliased`, `Mapped`, `Awaiting` (the invocation is in a callback `map` runs) and `Indexed` (a computed call target, `iterated[0]()`: SC9012's own uncertifiable row, `computed-call-target-unresolved`, answers it); `Emitting` and `ClassEmitting` (the invocation is inside a method the continuation calls: the row stands at the invocation in the method, wherever the call of the method is). `Parameter` is a violation the walk already proved by following the argument (ADR 0669). Silent: `Before` (invoked before the await: tracked), `Handler` (an event runs it), `Resolved` (a function declaration and a `const` bound to an arrow: nobody stored them). **Batch 10c (B1)** closes the spellings the Fable review of batch 10b found silent, all the same fact (Chrome warned at each read): `Slot` (`slot.cb()` over a member of a typed object the program assigned), `OptionalSlot` (`?.()`), `SlotCall` (`slot.cb.call(undefined)`), `InterfaceSlot` (a method signature has no body; the object names a function), `Dispatch` and `Apply` (`.call` and `.apply` run the receiver), `Reassigned` (a `let` written again holds the later function), `StoredTag` and `StoredTagIndexed` (a tagged template calls its tag where it is written), `StoredNew` (`new` of a stored function). Each is an `unresolved-invocation` row at the invocation (at the `new` keyword for a construction, where V8's frame stands). Silent: `Declared` (a `let` nothing writes again, a class and a tag function the program declared, `Math.max.apply`, a method with a body: nothing was stored). `stored-function-after-await-none` is the program with no async computation: no row.

Cost: every unresolved invocation after an await in a tracked or handed async function is a row, whatever it stores (corpus: ADR 0964). Not covered, an open class: `docs/open-work.md`.
