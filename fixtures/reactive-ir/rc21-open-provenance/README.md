ADR 0665-0667: a source whose first argument no fact proves sync or async (an `any` or `unknown` return, a value of unknown shape, a compute that names `NotReadyError`, directly, by namespace or in a helper) is an uncertifiable SC5001 and SC5003, and its strict read an uncertifiable SC1001, blocker `async-provenance-unproven`. A closed return, a data value and a user's own error class stay proved. A `lazy` tag with no boundary is uncertifiable, and certified under `Loading`. A read in an object method nothing places is uncertifiable under both rules.
