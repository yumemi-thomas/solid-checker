# member-routes-after-await

**Claim (ADR 0963, batch 10b group A).** Code run by a route no call shows (a getter or setter, a coercion method, an iterator-protocol method, a Proxy trap, a constructor, a class field's initializer, a tag function, a function only `new` runs) may run on the continuation of an async tracked computation: the access that runs it is no call, and the walk of the continuation follows calls. A source read there is untracked after the `await`, and Chrome (rc.21) warns `UNTRACKED_READ_AFTER_AWAIT` at it; the program was certified clean for SC1002, beside only SC1001's uncertifiable row (another rule's row covers nothing of the claim). Each read in a member the program holds is an uncertifiable row of SC1002 (`function-run-unplaced`; `field-initializer-unplaced` for the read directly in `WithField`'s initializer) while the program holds an async tracked computation with something after a suspension. Never a violation (nothing here proves the continuation runs the member), never silence.

`App.tsx`: `ObjectAccessor` (the getter and the setter), `ClassMembers` (a class getter and a method called as `counter.total()`), `Coercion`, `Iteration`, `Trap`, `Constructed` (a constructor, a field's initializer), `Tagged`, `ThroughHelper` (the read is in a helper the getter calls). **Batch 10c (B2)** closes the same routes written as function values, which the review of batch 10b found silent (Chrome warned at each read): `ArrowCoercion` (`{ toString: () => … }`), `ValueOfFunction` (`valueOf: function () …`), `ArrowTrap` (a `get` arrow of a `new Proxy` handler), `ArrowThenable` (a `then` arrow, awaited), `FunctionIteration` (`[Symbol.iterator]: function* …`), `NamedFunction` (`{ toString: named }`: the function is the one the name is bound to), `AssignedMember` (`o.toString = () => …`), `PrototypeMember` (`K.prototype.toString = function …`), `DescriptorGetter` (the `get` of an `Object.defineProperty` descriptor). The key decides, not the spelling: the host calls the keys of a coercion (`toString`, `valueOf`, `toJSON`, `toLocaleString`), of the promise protocol (`then`), of the iterator protocol (`next`, `return`, `throw`), `handleEvent`, any computed key no literal decides, a `new Proxy` handler's trap names and a descriptor's `get` and `set`. A function stored under any other key runs by a call of that slot, which `stored-function-after-await` answers at the call. Silent: `Handler` (an ordinary closure) and `Never` (a class nothing constructs or names). `member-routes-after-await-none` is the same program with no async computation: no row.

Cost: a read in a member is a row whatever the continuation touches (a member the computation never reaches, a source it already tracked before its first suspension). A function stored where nothing follows it and invoked through an unresolved call after the `await` (`callbacks.forEach((c) => c())`) is ADR 0964's: `stored-function-after-await`.
