# write-named-closure-in-tracked-scope

**Claim.** A closure bound to a name inside a tracked scope (a memo or effect compute, a tracked JSX expression) is constructed there, not run there, so the scope's role (`TrackedJsx`) is no proof that its `SC2001` write throws: the closure runs where it is called (ADR 0452). A closure only returned or stored (`Returned`, `ReturnedDeclaration`, `Stored`) has no call to place and is uncertifiable, as the anonymous form (`Inline`) always was; a call in the scope's own pass (`CalledInCompute`, `CalledInComputeAndReturned`, `CalledInJsxExpression`) is a proven violation; a call only in a leaf scope (`CalledInLeafScope`) reports nothing. The calls decide whatever the nesting or the name: a write one level inside the closure through an IIFE or an inline callback (`CalledNestedIife`, `CalledNestedInlineCallback`), an alias, a call before a hoisted declaration, an outer closure calling an inner one, and a capitalized name (`CalledCapitalized` is a violation, `ReturnedCapitalized` uncertifiable); a closure that returns JSX is a possible component and is decided by component identity (`ReturnedJsxClosure`). A default value is part of the closure: a write in one runs when the closure is called without the argument, so `ReturnedDefaultWrite`, `ReturnedAnonymousDefaultWrite` and `ReturnedDestructuringDefaultWrite` are uncertifiable (rc.17: a click writes, nothing throws); a closure with code in its parameter list has no call sites (ADR 0339), so `CalledInComputeDefaultWrite` and `CalledInComputeNonLiteralDefault` are known misses and `CalledInComputeLiteralDefault` a violation. A function written inside a default value (an IIFE, an inline callback) belongs to the closure that owns the default (`ReturnedIifeDefaultWrite`, `ReturnedForEachDefaultWrite`, `ReturnedMapDefaultWrite`: uncertifiable; called in the compute they are known misses like `CalledInComputeDefaultWrite`), and a helper's own calls do not run the default of a closure it builds (`HelperReturnsDefaultClosure`, with the body-write control `HelperReturnsBodyClosure`). Stub: `createSignal`, `createMemo`, `createEffect` and `onSettled` shapes of rc.17.
