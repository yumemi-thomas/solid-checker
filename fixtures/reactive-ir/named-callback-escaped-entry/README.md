# named-callback-escaped-entry

**Claim (ADR 1119).** A read in a function a primitive names by its binding (`createMemo(cb)`, `onClick={cb}`, `onSettled(cb)`) takes that position's silent role only when every reference to the binding is a position the named-callback index records, a call the call graph resolves (classified at the call), the declaration or a type query, and no unseen code enters it (`write_roles::role_entries_complete`). A `const` alias counts when its own references are accounted the same way. Any other reference (an array element a carrier later calls, a global store, an export) is an entry the role does not describe: SC1001 uncertifiable (`function-run-unplaced`, arm `callee_roles.named-callback-entries-open`), never a silent clean.

Clean: `MemoOnly`, `MemoThroughAlias`, `MemoAndUntrack`. Uncertifiable: `MemoAndGlobal`, `AliasEscapes`. ADR 1166: `MemoAndCarrier`, `HandlerAndCarrier` and `SettledAndCarrier` are violations, the body's `forEach` a run that executes the read (`named-callback-reporting-run`). Writes already need the census (ADR 0516). Chrome (`runtime-oracle/named-callback-escaped-entry`): STRICT_READ_UNTRACKED at the three carrier cases, which main left clean. Stub: `leaf-scope-named-callback`'s, plus rc.21's `untrack` (`core.d.ts:204`) and a `button`.
