A component whose only escapes are elements handing it an enclosing component's own props whole (`<Writer {...props} />`, ADR 0919) receives what the enclosing component's call sites pass (ADR 1173): `passed_sources` takes them as witnesses (complete when every forwarded-from component's are), and `prop_use`/`accessor_value_use` prove a name static through the forwards. `Body`: `props.setW1(7)` in `Writer`'s body is SC2001 (main: SC9012 `closed-parameter-member-dispatch`). `Apply`: the same call in an effect's apply is silent. `Override` (the forward sets `setW1` after the spread) and `Rest` (a spread of a plain object) keep their uncertifiable rows.
