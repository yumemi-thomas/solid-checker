# merge-omit-view-spread

**Claim (ADR 1129).** A `merge` or `omit` view of a component's own props, spread onto an intrinsic element, hands the element the keys the component's callers write (and the view's literal keys), minus the `omit` keys, when every reference to the component is a JSX tag with no spread and no namespaced attribute, and every reference to the props and to the view bindings is a chain argument, a member read, an intrinsic spread or a type query. The spread's SC8003 (`spread-content-unproven`) and SC4001 (`handler-spread-unresolved`) obligations then close where no content key and no unresolved listener can reach it.

- Proved (clean): `Badge` (the cheatsheet's Props helpers: defaults by `merge`, the rest by `omit`), `Button` (a caller's listener reaches the spread as that function; `children` omitted), `InlineOmit` (`omit` in the spread), `MergedOnly` (a `merge` view alone), `NamespaceOmit` (`Solid.omit`, the exact primitive through a namespace import), `Split` (a `merge` view for the component's keys beside the `omit` view it spreads), and SC8003 of `GetterListener`.
- Misuse twins, uncertifiable: `Html` (a caller writes `innerHTML`, which reaches the spread beside the children) and `ChildrenThrough` (a caller's `children` beside the element's own `innerHTML`).
- Refused, uncertifiable: `Shadowed` (a project `merge`), `Member` (`helpers.omit`), `Wrapper` (a project function returning `omit(...)`), `DynamicKey` (a non-literal `omit` key), `Predicate` (an `omit` predicate), `SpreadCaller` (a caller spreads into the component), `AsValue` (the component is also a value), `WritesProps` (the component writes its props), `CallsMember` (a view's member is called, which hands the view as `this`), `LeakedView` (the other view of the props is handed to a function), SC4001 of `GetterListener` (a literal's listener is a getter), `Exported`.

The prop types declare a content key and a listener, as `JSX.HTMLAttributes` does, so no declared key set (ADR 0436) closes these spreads first. `solid-js.d.ts` copies the published `merge`, `omit`, `Merge` and `Omit` declarations of `@solidjs/signals@2.0.0-rc.21` `dist/types/store/utils.d.ts`, as `merge-omit-view-props-call` does; `tsc --noEmit` accepts the fixture against the real rc.21 packages (the runtime oracle's copy), and Chrome runs it quietly (`scripts/runtime-oracle.mjs --cases fixtures/reactive-ir --only merge-omit-view-spread`). The view semantics are read from `@solidjs/signals@2.0.0-rc.21` `dist/dev.js` (`mergeLookup` 9247-9283, `mergeTraps`/`omitTraps`, `merge` 9576-9683, `omit` 9684-9707, `ownEnumerableKeys` 3107, `isHidden` 8766), `solid-js@2.0.0-rc.21` `dist/solid.dev.js` (`createComponent` 1403, `observedComponent` 64-90) and `@solidjs/web@2.0.0-rc.21` `dist/web.dev.js` (`spread` 683, `collectProps` 980), as `scripts/fuzz/install/package-lock.json` pins them.
