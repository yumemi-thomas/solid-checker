# handed-carrier-tracked

**Claim (ADR 0776).** A named function a carrier provably runs at a tracked position reads there, with no boundary: a proved SC5003 (`[1].map(hf)`, `hf.call(null)`, a module function, a two-element `sort`). A carrier under `Loading` with the function outside it (`g2a`) and an empty literal (`g2b`) stay certified: the cover and the run are the carrier's, not the function's.
