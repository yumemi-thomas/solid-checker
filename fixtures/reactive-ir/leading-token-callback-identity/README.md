# leading-token-callback-identity

**Claim (ADR 0376).** A callback, a callee or a call/apply receiver is a function's identity only when it is that function's identifier (TypeScript wrappers kept, ADR 0346). The entity at a compound span names its leading token, which is not the value: `createMemo(makeCompute())` and `createEffect(count, makeApply())` run the factory in the click handler (clean), `setupMember.child.call(null)` runs `child` and `trackMember.toString()` calls nothing (clean, no SC4001). Controls keep their proofs: `createMemo(computeWrites)` SC2001, `createEffect(count, applyReads)` SC1001, `setupCalled.call(null)` and `trackCalled(…)` SC4001. Owners: `NamedCallbackIndex::identity_at`, `returned_binding_reference`, `call_edge_symbol`. Stub: `callback-containment`'s plus `createReaction` from rc.17's `@solidjs/signals` typings.
