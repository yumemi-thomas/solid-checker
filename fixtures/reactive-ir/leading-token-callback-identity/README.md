# leading-token-callback-identity

**Claim (ADR 0376).** A callback, a callee or a call/apply receiver is a function's identity only when it is that function's identifier (TypeScript wrappers kept, ADR 0346). The entity at a compound span names its leading token, which is not the value: `createMemo(makeCompute())` and `createEffect(count, makeApply())` run the factory in the click handler (clean), `setupMember.child.call(null)` runs `child` and `trackMember.toString()` calls nothing (clean, no SC4001). Controls keep their proofs: `createMemo(computeWrites)` SC2001, `createEffect(count, applyReads)` SC1001, `setupCalled.call(null)` and `trackCalled(…)` SC4001. A tracker's invocation reads the owner edge's answer (`invoked_function_span`): `trackCall.call(null, …)`, `trackApply.apply(null, […])`, `trackBound.bind(null)(…)`, a `const` alias of `trackAliased.bind(null)` called, and `setupBound.bind(null)()` are SC4001; a `bind` result nothing calls is clean. The tracking argument of `call`/`apply` stays an uncertifiable SC1001 read (its slot shifts). `leading-token-bind-patched` pins the ADR 0338 tripwire. Owners: `NamedCallbackIndex::identity_at`, `returned_binding_reference`, `call_edge_symbol`, `invoked_function_span`. Stub: `callback-containment`'s plus `createReaction` from rc.17's `@solidjs/signals` typings.
