# store-write-literal-links

**Claim (ADR 0491).** A store write past the root is a violation when every link it reads holds the literal the store's initializer wrote and nothing can replace or reach that raw value: a function-local `const [store, setter?] = createStore(<closed object literal>)`, the setter absent or unreferenced, every reference to the store (or an exact `const` alias) the root of a static path that is written, deleted, called as a callback-free array mutator, or read where the literal holds a primitive. Each link is then served wrapped (rc.17 `isWrappable`), so the write is dropped (`STORE_WRITE_OUTSIDE_SETTER`).

Violations: `Literal` (`store.a.v`, `store.items.push(1)`, `store.deep.b.c`), `Alias`, and through ADR 0480's literal slots (ADR 0497) `HookSlot` and `TupleSlot`, and through a hook holder read only by static members (ADR 0500) `HookMember`. Uncertifiable (ADR 0476 unchanged): `SetterUsed`, `FrozenLink`, `Escapes`, `RootEscapes`, `NamedInitial`, `Spread`, `Getter`, `SortCallback`, `ModuleScope`, `RegexLink` (served raw), `CastPrimitive`, `DirectEval` (`Eval.ts`: a direct `eval` anywhere in the file), `Reverse` (may write nothing), `TupleRest` (a rest element takes the store), `HookKept` (a call keeps the whole object), `HookNested` (a nested pattern reads a proxy out), and from the ADR 0497 review `TupleSpread` (a spread shifts the index), `HookQuotedKey` and `HookEscapedKey` (keys not written as plain identifiers, beside a method), and for ADR 0500 `HookMemberPassed`; silent, a known miss (no member alias, so the root is not proven the store): `HookMemberKept`, `HookMemberWritten`, `HookMemberComputed`, and from the ADR 0500 review `HookMemberValueOf` (a key the literal lacks reads `Object.prototype`) and `HookMemberThisReset` (a `function` value runs with the holder as `this`); their root writes are unaffected. Stub: `store-write-chain-links`'s.

Variant `eval` (`DirectEval`, ADR 0803 item 3): a direct `eval` anywhere may patch array iteration, withdrawing every primitive's tuple slots, so it lives apart and pins the withdrawal. The store Gets of these uncalled exports are SC1001 uncertifiable (ADR 0934).
