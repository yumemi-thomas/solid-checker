# A consumer of member returns

Written to pin a contract whose closed `returns` hands back a member of the caller's argument (`callHandler` as declared by `@kobalte/utils@2.0.0-alpha.0`, `EventHandlerUnion` reduced): `Handler` clean, `HandlerOpen` `SC9005`, `PassThrough` `SC1001`, `MemberRead` clean by design. Package contracts are removed (ADR 0312). Today the only finding besides the SC9014 notice for the rc.0 stub is `SC9011` `reactive-source-uncaptured` (uncertifiable) at the `count` argument of `PassThrough`'s `passThrough(count)()`; `Handler`, `HandlerOpen` and `MemberRead` are silent, and no SC9005 is raised because the stub package declares no `solid-js` peer dependency. The closed/open control is no longer pinned. The `solid-reactivity.json` beside the stub is inert.
