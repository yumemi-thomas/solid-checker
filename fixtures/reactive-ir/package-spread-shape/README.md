# package-spread-shape

ADR 0372: a spread of a call of an installed package's export hands an intrinsic element only the own keys the export's every return holds, read from the package's runtime file as ADR 0284 selects it (declared browser/development host). With no event key among them the spread hands no handler: no SC4001 obligation at the spread, and the `onClick` written before it is not replaced (ADR 0364), so its ownerless `onCleanup` is a violation (`NamespaceAttrs`, `NamedAttrs`, `Stylex`). A parameter return, a computed key, an `onClick` key, an export binding its own module rewrites, a package with declarations and no runtime source, and a local binding shadowing the import keep the obligation, and the handler before them stays conditional.

The entry is read as ADR 0284 selects it only under ADR 0297's premise, a Solid Vite plugin resolving from the project; here that is the group's `fixtures/reactive-ir/node_modules/@solidjs/vite-plugin`. Variant `solid-condition` imports `cond-pkg`, whose `solid` entry returns `class` and whose `default` entry also `onClick`: with the plugin the `solid` entry loads and the `onCleanup` is a violation; `rust/crates/solid-facts-backend/tests/package_returns_process.rs` runs it from a copy outside the group, where no plugin resolves and the spread keeps its obligation.

`node_modules/@stylexjs/stylex` holds published bytes of `@stylexjs/stylex@0.19.0` (`package.json`, `lib/es/stylex.mjs`, `lib/es/stylex.d.ts`, `lib/es/types/*.d.ts`; integrity `sha512-CnUFp7YMaDLDeemsWOfJgoC/gKM5P/yBNMcpJaE6ChJmXr7s0DJwSeGTTlHJcqqwN9OW1qGtmARWLFhGZN1pTA==`, copied from the rc.17 corpus install). `fake-styler`, `declared-only` and `cond-pkg` are synthetic packages with no published identity, one export per return shape.
