# write-callback-by-name

**Claim (ADR 0466).** A primitive that names a function by its binding runs it as it runs an inline callback in that position, so a write the function runs in place (an IIFE, an inline `forEach`, a helper that calls its callback) is placed as the inline form places it. Violations (rc.17 throws `REACTIVE_WRITE_IN_OWNED_SCOPE`, fast path): a memo compute (`MemoIifeByName`, `MemoForEachByDeclaration`, `MemoHelperByName`, `MemoIifeByNameAlsoHandler`), an effect or render-effect compute (`EffectComputeIifeByName`, `RenderComputeForEachByName`), a root body (`RootIifeByName`, `RootHelperByNameAlsoHandler`) and `untrack` in a body (`UntrackIifeByName`, `UntrackForEachByNameAlsoHandler`). Before, the memo and `untrack` layers were silent and the others uncertifiable. A function with other entries is a violation when the run the primitive gives it throws (one run is enough), never legal from that run alone.

Legal (rc.17 silent): no owner (`NullOwnerIifeByName`, `NullOwnerForEachByDeclaration`, uncertifiable before), a fresh stack (`MemoTimerByName`, `EffectComputeTimerByName`), `untrack` in a handler (`UntrackByNameInHandler`), a shadowed name (`MemoShadowedName`, `EffectComputeShadowedName`: the primitive names an inner `compute`), an effect apply (`EffectApplyIifeByName`).

Uncertifiable: a render-effect apply, whose first run is unproven as written inline (ADR 0460; `RenderApplyIifeByName`, `RenderApplyIifeByNameAlsoHandler`, silent before though rc.17 throws); no owner with another entry the walk does not place (`NullOwnerByNameAlsoHandlerCall`); a `let` that is reassigned (`MemoReassignedName`); costs where rc.17 throws: an alias (`MemoAliasedName`) and a name used in a nested function, which may run before a `const` is initialized (`RootByNameInHandler`). Stub: rc.17 shapes (copied from `write-owner-in-cleanup`).
