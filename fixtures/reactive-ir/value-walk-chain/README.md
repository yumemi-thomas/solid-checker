# value-walk-chain

**Claim (ADR 0800).** A value's walk has no length limit. `caught-at-five` and `caught-at-seven` catch a pending read through helpers, Chrome (rc.21) reports CAUGHT_REACTIVE_READ, and SC5008 stands at each; the build before dropped it at four hops. `caught-past-budget` runs past the walk's 256 values: undecided opens, so SC5008 stays uncertifiable. `settled-past-budget` is its quiet twin, and has no SC5008.
