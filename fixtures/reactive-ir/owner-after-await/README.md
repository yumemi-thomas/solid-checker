# owner-after-await

An owner-requiring operation (`onCleanup`, an effect, a contract call with an owner requirement) that runs after an `await` on every path through its async function has no owner, whatever it was entered with: a proven `SC4001` (`owners::AwaitContinuations`); before the first `await`, on one-branch awaits and after non-awaiting `catch` it is none, and an owner restored with `runWithOwner` is not a violation. Runtime (rc.0-rc.9): `getOwner()` is `null` after the `await` (`NO_OWNER_CLEANUP`/`NO_OWNER_EFFECT`). Stub: `fp-owner-leaf-helper-after-await`'s plus `getOwner`/`runWithOwner` verbatim from rc.9.
