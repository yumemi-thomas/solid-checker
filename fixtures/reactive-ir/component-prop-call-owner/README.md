A component prop's function literal whose every run is a call `props.run()` the child writes runs where each call is written (ADR 1171): the child is rendered at that one tag and nowhere else, the element has no spread and one attribute of the name, `props` is a plain parameter used only for member reads, and every `props.run` is a call's callee. The owner graph takes an edge from each call, and the entry walk reads the calls as the literal's entries. `Body` (called in the child's body) is silent; `Apply` (called in an effect's apply) is an SC4001 violation, NO_OWNER_CLEANUP. `Never` (never called), `Twice` (rendered at two tags), `Held` (`props.run` read as a value) and `Spread` (a spread may supply `run`) keep their uncertifiable rows. Closed boundary (`.solid-checker/runtime.json`).
