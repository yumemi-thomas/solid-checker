# flow-iife-tracked

Claim (ADR 0834): a function run in place in a tracked JSX expression of a control-flow row (`<For>{() => <p>{(() => …)()}</p>}</For>`: an IIFE, the layers it calls, an inline library callback) runs in that expression's insert, so it is placed as tracked, as the same expression outside a flow row is. `ResolveInRow`: `resolve` there is an `SC2004` violation (rc.21 in Chrome: "Cannot call resolve inside a reactive scope", then REACTIVITY_HALTED); it was uncertifiable (observer-callers `InFlowJsx`). `PendingInRow`: an async memo read through a helper chain the IIFE runs is `SC5003` uncertifiable (W's `for` wrapper chain-5, certified before). `ResolveInRowHandler`: a handler in the row keeps its deferred answer, silent (Chrome quiet). Stubs as in `observer-callers`.
