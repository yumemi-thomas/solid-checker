# Exact argument guards for owner and leaf requirements

Written to pin exact argument guards (`Literal(true)`, `Property(resize, callable)`, `Literal(length = 2)`) on a package's owner and leaf registration requirements: proving literals would be violations, disproving ones clean, nonliteral or spread arguments uncertifiable. Those requirements came from a package contract, which is removed (ADR 0312). Today the module-scope calls report nothing, and each of the twelve `start*` calls inside `Leaf`'s `createTrackedEffect` callback is an `SC9012` `reactive-dispatch-unresolved` uncertifiable result, whatever its arguments; the snapshot also holds the SC9014 notice for the rc.0 stub. The guards are no longer exercised. Solid signatures come from `package-leaf-registration-consumer`'s published rc.9 stub. The `solid-reactivity.json` beside the stub is inert.
