# owner-call-jsx-getter

**Claim (batch 11, B2 of the re-review of #220; the review of #225, F2; ADR 0971).** A component element's children, and the value of its props, are a getter that runs where the component reads it; whatever the getter's own evaluation creates (a JSX creation or a creating call, in the getter itself or in a function it calls in place) runs there. Read on an effect's apply, the getter's tag is created on a stack with no owner (rc.21 PRIMITIVE_IN_EFFECT_CALLBACK, SC6002), and where a leaf owner's callback reads it the tag is a forbidden creation (PRIMITIVE_IN_FORBIDDEN_SCOPE, SC3001). The first build of ADR 0971 skipped the tag as "a getter's, read where the component reads it", and no row stood at the read for these codes (the SC1001 at the read does not claim them), so the program certified, as it did on main and on the head of #220. A getter's creation is a site now: it is ended by the silences of any site that apply to a getter (the component never runs, the module has no owner), by an in-place renderer, which reads its children under its own owner (the dialect's `Show`, `For`, `Index`, `Repeat`, `Switch`, `Match`, `Loading`, `Errored`, and a context provider), or not at all; what nothing ends is the code's own uncertifiable row (decline `getter-runs-where-read`), never a violation. The checker does not prove where a getter is read (`stored_throw.rs::prop_reads` could, later), so every getter whose component is not an in-place renderer has the two rows: the named cost.

The Chrome oracle case is `fixtures/runtime-oracle/owner-call-jsx-getter`: the head of #220 and the first build of B2 are `unproven-clean` at the tags `Outer` and `Leaf` read, the fix is `covered-uncertifiable`. The fuzz cells are `er-slot-apply`, `er-children-apply`, `er-slotcall-apply` and `er-childcall-apply` and their never-run twins (the child component reads nothing) with the JSX variants. The grid's component is an export of an open program, where B3 files a row at every site written inside it, so its cells cannot tell a getter's own proof from B3's hand-off; this fixture, whose program is closed, carries it.
