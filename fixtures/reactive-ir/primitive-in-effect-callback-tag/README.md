# primitive-in-effect-callback-tag

**Claim (ADR 0586).** The effect-phase walk crosses a template tag (``hf`x` ``, ADR 0538's inline carrier) to the tag function's body, but counted the carrier's own tag as a call that runs earlier in the apply, so a computation created in the tag function was SC6002 uncertifiable while ADR 0561's tag owner edge made SC4001 prove the same effect unowned (mx-pairs `effect-apply` × `handoff-tagged`, 35 `wrong-rule` programs). The tag of the template the path is runs the path, as a plain call's callee does: `EffectThroughTag` (SC6002 and SC4001) and `MemoThroughHelperTag` are violations. A call in the substitutions (`SubstitutionCallFirst`) or before the template (`CallBeforeTag`) still runs first: uncertifiable. Clean: the tag under `runWithOwner(owner, …)`.
