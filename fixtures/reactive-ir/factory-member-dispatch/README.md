# factory-member-dispatch

**Claim (ADR 0314).** A helper invoking a parameter member resolves it when the argument is a `const` bound to a plain call of one exact, current, synchronous project function whose every return is an object literal written in the return, each holding the member as an own property with no assignment or reflective definition naming it (`factory_member_value_symbols`); getters, shared/nested results, argument literals, method calls, `let`, destructuring and reassigned members are `SC9012`.
