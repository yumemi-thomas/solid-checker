# effect-cleanup-rerun-read

ADR 0539: full-7 (2026-11-01) certified clean 3,828 rc.17 SC1001 warnings in the effect-window cells `effect-cleanup-rerun` and `render-cleanup-rerun`: a read in the cleanup an effect's apply returns. rc.17's `runEffect` opens the strict-read window before it calls the previous cleanup (`@solidjs/signals@2.0.0-rc.17` `dist/dev.js:1991-2005`), so the read warns on a rerun; the owner's disposal calls the same cleanup outside the window, and nothing orders that disposal against the rerun. Such a read is an obligation where no rerun is proven: NamedApply (applies passed by name; since ADR 1200 the `const` one with its one reference is the inline apply, a violation, while the declared one and the others keep the obligation; its third apply hands a named reader to `forEach` in the cleanup, whose unplaced carrier is an obligation though a named callback nests it).

ApplyRead's read in the apply itself stays a violation. NeverReruns stays silent (since ADR 1167 also for SC1001, which was uncertifiable): a compute with no call, no reference and a literal return tracks nothing, so only a disposal calls the cleanup. TrackedCleanup is unmoved (a tracked effect calls its cleanup inside its compute, tracking; it keeps an earlier obligation). UntrackedCleanup is silent. ShadowedEffect's project function named like the primitive takes none of this (its findings are the pre-existing escape obligations).

The stub reduces the published rc.17 declarations. The complete source also type-checks against published solid-js rc.17 with strict ES2022 settings. Package bytes are not copied here.

ADR 1183: `EffectRerun` and `RenderRerun` are violations (Chrome rc.21 `runtime-oracle/effect-cleanup-rerun-read`: STRICT_READ_UNTRACKED after the click): the click writes a new value to the signal the compute reads, a write a user can reach, so the rerun runs the cleanup in the window with the owner alive. The other shapes keep their obligations.

ADR 1195: RerunThroughLayer (a project helper's callback run in place in the cleanup) is an SC1001 violation: a reached click (`setTick(2)`) reruns the effect, whose first run returned the cleanup (ADR 1183's proof, placed through the layer). EffectRerun and RenderRerun, a read in the cleanup's own body, are violations since ADR 1183.
