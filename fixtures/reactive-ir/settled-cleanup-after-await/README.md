# settled-cleanup-after-await

**Claim (ADR 0488).** `onSettled` called after an `await` its async function reaches on every path runs on a continuation with no owner: a callback that returns a cleanup throws `SETTLED_CLEANUP_UNOWNED` (`missing-owner`, SC4001), as anywhere unowned. Not proven (uncertifiable, unchanged): the call before the `await`. Clean: a callback that returns nothing. Stub as in `owner-leaf-nested-cleanup`. ADR 0516: a call a loop's later iteration or a skippable `await` may put after the suspension is uncertifiable (`LoopAwait`, `SkippableAwait`, and `LoopAwaitLater`, whose registration runs only on a later iteration: silent before); a loop's callback that returns nothing stays clean (`NoCleanupLoop`).
