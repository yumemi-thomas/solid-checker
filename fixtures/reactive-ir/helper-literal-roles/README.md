# helper-literal-roles

**Claim (ADR 0442).** A function literal (or a same-file function named by identifier) handed to a project helper takes, for its writes, the role of the call that handed it over when the helper invokes its parameter during that call, found for each invocation of the parameter and for that activation alone: handed over in the component's body, or in a function the body calls, the write is `SC2001`; handed over in an event handler, or in a function only handlers call, it is clean, though the same helper is called from a body elsewhere in the program; handed to a timer it runs on a fresh stack. A helper that keeps its callback (`later`) leaves the obligation. Stubs: `solid-js.d.ts` is `forwarded-event-prop`'s; `.solid-checker/runtime.json` closes the program boundary, so the exported helpers' call sites are all the program's (ADR 0442).
