# after-await-universe

**Claim (batch 11, slice 9B; ADR 0973).** Every read and every call that may run a project function, written after an async function's own suspension, ends in a row of SC1002, an SC9012, the compiler's discard or a typed reason (`after_await_accounting.rs`); a site that ends in none gets an **uncertifiable row of SC1002, blocker `read-after-await-unaccounted`**: never a violation, never a silence. UNTRACKED_READ_AFTER_AWAIT's producers walk only from a tracked async computation, so a read or a call they never reach had no row and no record of why. There is no callee reason: a call keeps its row whatever its callee does.

This program holds a tracked async computation with something after a suspension (`Tracked`), and no site below is that computation's own. Each site below is silent on main (SC1001's own rows are as before); the unaccounted row is the only change.

| site | outcome | why no reason ends it |
|---|---|---|
| `count()` in an async `onClick` handler, and `count()` in the exported helper `helper` | SC1002 uncertifiable, `read-after-await-unaccounted` | the read is after an await of a function no computation runs; nothing walks it. A role silence (a handler, a deferred callback) is left out on purpose: each needs a premise and a Chrome twin of its own (open-work) |
| `stringify(1)`, `readsCount()`, `ping(3)` | the same | calls of project functions (a callee that calls the standard library, one that reads a source, one that calls itself): no callee reason |
| `helpers.format(1)` (a namespace import: another module's function, resolved exactly) | the same | the same |
| `codec.encode(1)` and `meter.read()` (methods of `const` object literals: exact members, ADR 0279) | the same | the same |
| `this.helper()` (in `Loader`'s own async method) and `loader.helper()` (a receiver typed as the class) | the same | the walk's resolver finds the method and cannot say it is the one that runs (a subclass may override it, a replacement may stand in): an inexact member |
| `callback()` (a parameter) and `reassigned()` (a reassigned `let`) | the same | a call of a function value no exact declaration resolves (ADR 0964's shape) |
| `count()` after `for await` | the same | an implicit suspension is a suspension |
| `peekAlias()`, `peekStored()`, `peekProxy()`, `peekDescriptor()` (`ByClosure`, in a recognized computation) | the same | **B1 of the review of #233.** A callee whose closure lists no read still runs one: a store read through an alias binding, a stored generator stepped by a spread, a Proxy trap and a getter installed through a handler or a descriptor declared apart. Chrome rc.21 reports the code under each call (the oracle case `after-await-closure`); a callee reason (the first build had one) ended them silently |
| `registry.run()`, `registry["run"]()`, `registry?.run()`, `registry.tick()` (`work`, handed to `track`) | the same | **B2.** A method, a computed and an optional member and an arrow property of a module-scope `const` object literal the receiver census withholds (ADR 0299): the lookup names no project function, and the call left the pass through a `continue`. Now a site (`project` or `unresolved`) |
| `reader.call(undefined)`, `reader.apply(undefined, [])`, `Reflect.apply(reader, undefined, [])`, `(() => count())()`, `(function () {…})()`, `await (async () => count())()` | the same | **B3.** A standard call that runs a function value its receiver or arguments name (`apply`) and a function literal called where it is written (`iife`): each runs a project function on this stack (the oracle case `after-await-calls`) |

What stays without a row (`Outside`; each named in `docs/open-work.md`, S1 to S3 of the review): `JSON.stringify(…)` and `Promise.resolve(…)` (a standard-library declaration runs project code only through a callback or a protocol the project's objects implement), `setCount(1)` (a setter has rules of its own) and `new Date()` (a constructor runs where no call shows). The process test `after_await_accounting_process::a_call_into_the_standard_library_or_solids_own_is_no_site` pins them, so the one arm that skips a call does not grow.

The twin `after-await-universe-none` holds the sites the one typed reason ends (no row) and the pure callees that keep theirs, `after-await-universe-census` a program with no recognized computation, where every site keeps its row (there is no census reason). `node_modules/solid-js/package.json` selects the dialect; `solid-js.d.ts` declares what the program calls.
