# Context forwarding refusals

Two providers, a guarded wrapper plus alias escape, object aliases, an opaque
wrapper escape and callback-fed member replacement must remain non-violating.
The plain member has no reactive origin. Contexts use distinct names so their
independent censuses are not masked by one shared veto. Stubs preserve the
claim-bearing published rc.13 signatures; real-package typechecking is separate.

Destructuring defaults/rest and a selected member passed onward remain refused.
Quoted and Unicode-escaped keys are outside the admitted plain identifier pattern.
A coalescing expression whose result is stored is an escape, even when its
left operand tests the context binding. Pure tests permit no other new use.
