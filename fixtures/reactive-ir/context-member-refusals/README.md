# Context forwarding refusals

Two providers, a guarded wrapper plus alias escape, object aliases, an opaque wrapper escape and callback-fed member replacement stay non-violating; the plain member has no reactive origin. Destructuring defaults/rest, a selected member passed onward, quoted/Unicode-escaped keys and a stored coalescing expression are refused. Contexts use distinct names so independent censuses are not masked. Stubs preserve published rc.13 signatures.
