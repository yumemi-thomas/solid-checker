# leaf-scope-named-callback

**Claim.** A signal write in a function a leaf primitive names by its binding (`createTrackedEffect(cb)`, `onSettled(cb)`) runs under a children-forbidden owner the runtime's write guard exempts, exactly as the same function written inline does (`WriteRegionAdjustment::LeafScope`): `no-write-in-pure-computation` is silent whatever the binding form (`Const`, `FunctionDeclaration`, `Let`, `NamedExpression`, `SharedTwice`, `Settled`, `HelperInside`). The tracked read role the position gives (`NamedCallbackRole::tracked`) is a read fact; only a tracked position with an owned computation (`NamedCallbackRole::tracked_owned`) rejects the write. `HelperInside`'s dispatch is also `reactive-dispatch-unresolved` (uncertifiable, as every helper layer's is); that is not a write claim. Violations: `MemoNamed` (the same function named as a memo's compute), `SharedWithMemo` (named at a tracked effect and a memo: the memo entry proves it), `RenderComputeNamed` (a render effect's compute, ADR 0466).

Runtime: rc.17's setter guard exempts `CONFIG_CHILDREN_FORBIDDEN` owners (`@solidjs/signals` dist/dev.js:2046-2090, dev-shared.js:5619-5638); the misuse matrix's `tracked` and `settled` legal cells across `CALLBACK_FORMS` (scripts/fuzz, Chrome-confirmed) reported 684 false positives on the `tracked` cell before this claim. Stub: `leaf-scope-helper-completion`'s.
