# impostor-prototype-reach

ADR 0876: a write whose own chain reaches a standard prototype is a patch of any owner, whatever spells it: `getPrototypeOf` here held by a
`let`. Each standard call stays uncertifiable, including a real `Promise.resolve().then`, and never a violation: the patched `then` runs
its callback at once, so what a standard `then` would prove is false both ways.
