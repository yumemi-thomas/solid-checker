# stored-throw-dynamic-mount

**Claim (ADR 1016).** A component mounted through `const D = dynamic(() => C)` and `<D />` runs where the tag is, so a plain throw in it (ADR 0893: `flush()` in a tracked effect, `useContext` with no provider, a static `dynamic` source) ends where `<D />`'s render does: Chrome reports it unless a boundary above takes it. The reading is taken only on exact facts: the dialect's own `dynamic` called by its bare name with one argument; that argument a parameterless, non-`async` arrow whose expression body is the component's name; a `const` whose every reference is a plain JSX tag name and that is not exported. Anything else stays the value use ADR 0893 asks of it: handled, so uncertifiable.

Violation: `MountsTrackedFlush` (SC3001, the plain throw of `flush()` in `createTrackedEffect`; the tag written with a closing tag).

Obligations (uncertifiable): `MountsUnderBoundary` (an `Errored` with a handling fallback above the tag: Chrome is silent), `MountsLetBinding` (`let D`), `MountsUsedOutsideTag` (D also pushed into an array), `MountsBlockBody` (the arrow has a block body), `MountsNamespaceForm` (`web.dynamic`: the dialect resolves it, the bare-name check refuses it), `MountsMemberForm` (`api.dynamic`), `MountsProjectDynamic` (a project function named `dynamic`, imported under another name; Chrome is silent, `C` never renders), `MountsShadowed` (a local `dynamic` shadows the import; silent too), `ExportedMount` (the `const` is exported). And `<D />` written where it never renders, so the component never mounts and Chrome is silent: `MountsNeverShown` (`<Show when={false}>`), `MountsFalseAnd` (`false && <D />`), `MountsDeadReturn` (after `if (false) return`), `MountsEmptyRows` (`<For each={[]}>`): only the tags reach analysis says may run count (ADRs 0458 and 1015), and with none the throw is unobserved.

Known miss: `MountsBodyRead` (SC4002, a default-less `useContext` in the body). The stored-throw walk now reports it, but the owner pass holds the row as `component-identity-unproven`: a function used only as a `dynamic` source is no proven component there. Chrome reports CONTEXT_NOT_FOUND. That side is its own ADR, not this one.

Runtime: rc.21 Chrome, oracle case `fixtures/runtime-oracle/stored-throw-dynamic-mount`: the flush is `covered-violation`, the bare-mount body read and the other value forms that render are reported by Chrome and covered by an uncertifiable row, the boundary and the two forms that never render are silent. Premises: the closed program is the `private` manifest.
