# rc21-flush-in-action-unplaced

Claim (ADR 0708): `flush()` in a function no call edge places (an object method, a class method or getter, a `Map` slot, a function handed by name to a helper, `toString`) that an action's body reaches runs with a step on the stack, and rc.21 dev throws `FLUSH_IN_ACTION` (measured in Chrome, witnesses SC2006 a02-a10). The position is not proven, so each is an SC2006 obligation with blocker `function-run-unplaced`, never a violation. The tag function was already an obligation (ADR 0538). Kept: a `flush()` written in the generator itself is a violation. Silent: a method of an object built in a function nothing calls. Stubs transcribe `flush` and `action` from `@solidjs/signals@2.0.0-rc.21`. The program without any action is `rc21-flush-unplaced-no-action`.
