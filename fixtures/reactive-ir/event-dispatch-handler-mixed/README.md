# event-dispatch-handler-mixed

Claim (ADR 0395, 0327): a dispatch in a function that is an event handler and is also called from a component body keeps the veto, since the census finds a non-event invocation: the sibling handler's write, read and effect creation are uncertifiable, none is a violation.

The stub packages carry only the version (2.0.0-rc.17) that selects the dialect release; `.solid-checker/runtime.json` closes the program boundary.
