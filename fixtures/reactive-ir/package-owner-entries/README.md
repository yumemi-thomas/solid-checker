# package-owner-entries

**Claim (ADR 0949).** A package function that creates an effect needs an owner, and an event handler has none. The handler answers for the entry, whatever form it takes: a call, `f.call(null)`, a tagged template, `new`, or a getter. Before ADR 0949 only the plain call was attributed (ADR 0290: an exact `CallFact`), and the package's own findings were dropped, so the other four forms were certified clean. Chrome (rc.21 development build): `NO_OWNER_EFFECT` at the project line of each.

`App.tsx` (package `node_modules/dep-owner`, a synthetic package of this fixture): every component's handler enters the package once. `Called` (`useTicker()`) is the call walk's violation (SC4001) beside an SC9012 obligation. `Dotted`, `Tagged`, `Constructed` and `Getter` are uncertifiable rows of **SC4001**, the rule that claims `NO_OWNER_EFFECT` (`function-run-unplaced`: no owner is proven current where the package code runs), and of SC9012 and SC6002 (`package-finding-at-entry:<code>`: the findings the package holds, dropped by ADR 0284 and standing again at the reference).

The SC4001 row is the rule's own, not the hand-off's. `useTicker`, `Ticker`'s constructor and `ui`'s getter reach no owner edge from a tagged template, `new` or a getter's holder, so the owner emission skipped each as a function that never runs from syntax and no requirement existed to attribute. `Emission::package_requirements` now records every owner-needing operation (effect, cleanup, boundary, settled cleanup, context read) of a package function that holds no owner context, and `attribute_package_entries` stands each at the calls and references that may run it: never at a render (the component runs under an owner of its own) and never at a call, `new`, tag or `f.call` written in a project function that holds an owner on every run (the owner is current there; `runs_owned_here`). A value handed on (`setTimeout(f)`, `onClick={f}`) is not decided by the owner around it, so it stands wherever it is written.

The build before ADR 0949 reported `Called` alone: the other four forms were certified clean.
