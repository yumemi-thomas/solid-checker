# rc9-flush-in-action-layers

Claim (ADR 0478): `flush()` in function layers that run in place inside an action step (an IIFE, `[x].forEach`, a helper in this file or another module that calls its callback in its body, nested) throws `FLUSH_IN_ACTION` on rc.8+ dev (the `flush-in-action` page's probe table: a synchronous helper throws), so SC2006 is reported at it. Silent: a layer after the body's first await, a call after an async IIFE's own await, a helper that keeps its callback, a scheduled callback, and a layer in the generator's parameter list. A named closure called once in place is claimed too (ADR 0479). Stubs as in `rc9-flush-in-action`.
