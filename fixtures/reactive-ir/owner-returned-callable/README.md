# owner-returned-callable

**Claim (ADR 0472).** An owner operation (`onCleanup`, `createEffect`) in a function its enclosing function returns, which no owner edge reaches, is uncertifiable, never certified: the owner walk does not follow a returned value to its later calls. Before, each case was certified. Uncertifiable where rc.17 reports `NO_OWNER_CLEANUP` or `NO_OWNER_EFFECT` (fast path): a plain factory's result called on a timer or in a handler (`FactoryResultOnTimer`, `FactoryResultInHandler`, `FactoryReturnStatementOnTimer`, `FactoryEffectOnTimer`, `FactoryIifeOnTimer`, `FactoryCalledTwice`), and a value returned through `runWithOwner(null, …)`, `createRoot`, `untrack` or a memo (`NullOwnerResultOnTimer`, `RootResultOnTimer`, `UntrackResultOnTimer`, `UntrackResultInHandler`, `MemoValueOnTimer`). The cost, uncertifiable where rc.17 is silent: a result called in the body, never called, or called in a root (`FactoryResultInBody`, `FactoryResultNeverCalled`, `FactoryResultInRoot`).

Unchanged: a cleanup written in a timer callback is a violation (`CleanupOnTimer`); a closure called in the body and a local `onCleanup` are certified (`ClosureCalledInBody`, `ShadowedOnCleanup`). Stub: copied from `write-callback-by-name`.
