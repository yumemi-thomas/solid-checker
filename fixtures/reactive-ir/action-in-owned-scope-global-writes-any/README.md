# action-in-owned-scope-global-writes-any

**Decision, pinned (ADR 0973; said first to the coordinator).** A package that writes a global under a name the syntax does not fix (`Object.assign(globalThis, source)` with a variable `source`, `window[key] = v`, `Object.defineProperty(globalThis, key, d)`) may have written any global. Treating that as "every global may be its" was built and measured: `storybook-solidjs-vite` writes so, and every `Math.max`, `JSON.parse` and `new Map` of a twelve-file project (kui `feature-alerts`) became a row (318 rows). The index records the writer (`PackageReachIndex::global_writers_any`) and does not follow it: `AnyGlobal` (`btoa`, which `source` holds, and `atob`) is silent here, a named miss in `docs/open-work.md`. The writer's own verdict stands (`global-object-escape`: a call into `fz-wany` is a site).

`node_modules/fz-wany` is **not** published bytes. `node_modules/solid-js` and `@solidjs/*` are the manifests of `action-in-owned-scope-unread-packages`.
