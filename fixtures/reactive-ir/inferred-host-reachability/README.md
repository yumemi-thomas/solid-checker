# Inferred host: static loadability and reachability

A browser host is inferred only from exact plain Vite commands in the app's own manifest (ADR 0270); launcher/shell/env/filter variants, enclosing-manifest Vite scripts, symlinks and active tsconfig-paths resolvers refuse. A module not proved loadable keeps the baseline; a literal throw proves its tail dead, an ordinary earlier call does not (premise A).

The pins are Rust tests, not the snapshot: `host-cases.json`, `resolver-selection-cases.json` and `conventional-selection-cases.json` are read by `inferred_host/tests.rs` (and `host_loadable/tests.rs` reads this directory), which also drive the runtime-resolution outcome rows. The snapshot holds the `SC9014` release notice (the rc.9 stub is an unaudited release) and one `SC7007` (uncertifiable: the RPC-only callback argument has no rich-argument transport proof), which is independent of the host. `isServer` is byte-faithful to `@solidjs/web@2.0.0-rc.13`'s published boolean signature; no stub is loosened.
