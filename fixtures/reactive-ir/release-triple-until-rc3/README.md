# release-triple-until-rc3

`until` arrives in `@solidjs/signals@2.0.0-rc.5`; on rc.3 `tsc` reports TS2305 on the import and neither runtime has the export, so `SC2005` cannot happen. The vocabulary knows `until` only where `solid-js` and `@solidjs/signals` both resolve to rc.5+. Expected: no `SC2005`, the `SC9014` release notice (the rc.3 triple is not the audited release), and an uncertifiable `SC1001` for the read in `until`'s callback, which an unknown name leaves unplaced; the same source over rc.5 reports `SC2005` (`rc9-until-scope`), so the silence is the release keying and not an absent rule. Only this snapshot pins it.
