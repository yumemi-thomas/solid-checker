# placement-blockers

**Claim.** An uncertifiable finding whose site no fact places names the missing proof in its `blocker` field (ADR 0367), and a proven finding names none. `component-children`: a handler factory call in a component element's children is SC1001 uncertifiable, while the same call on an intrinsic element outside any component's children is a violation. `deferred-apply`: a write in an effect apply whose `defer` option the syntax cannot read is SC2001 uncertifiable (ADR 0302), while the same apply with no options reports nothing. The other blockers are pinned on existing fixtures (`placement_blockers_name_the_missing_proof` in `rust/crates/solid-facts-backend/tests/diagnostics_process.rs`). Stub declarations are those of `unplaced-site-obligations` (published rc.13 typings); `node_modules` pins the rc.17 triple.
