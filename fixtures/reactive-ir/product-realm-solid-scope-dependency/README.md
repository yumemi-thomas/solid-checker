# product-realm-solid-scope-dependency

**The reach index does not walk Solid's own packages, so what their manifests depend on is held by manifest (review round 2).** `main.tsx` imports `@solidjs/router` (a stand-in): a package of the dialect's scope, which the reach index treats as Solid's own and does not walk, so a writer it loads is no writer of its root. Its manifest depends on `fz-prealm-any` (writes `Float32Array.prototype[Symbol.iterator]`), and `setup.ts` imports that package for the tests. The page loads `@solidjs/router`, which loads `fz-prealm-any`; the base (without ADR 1145) judges the product's sites against it, and so does the realm, because it holds every package the loaded packages' manifests depend on (`manifest_closure`). (On cc1795538 the realm dropped the writer: base 7 rows, realm 0.)
