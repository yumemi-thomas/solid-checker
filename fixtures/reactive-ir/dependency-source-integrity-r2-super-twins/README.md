# Package integrity review: super-twins

The twins of `dependency-source-integrity-r2-super-write` (ADR 0300, the check of #227, G2): a `super` that writes nothing of the slot closes the holder, so the descriptor write through it targets a fresh object and `location.search` stays the package's getter. `NoWrite` (`change` writes nothing of `slot`), `SuperRead` (a read through `super`) and `SuperOtherKey` (a write of another key through `super`) are SC1001 violations, on every build. `dep-router` is the package of the other `dependency-source-integrity-*` fixtures. Solid declarations are the published 2.0.0-rc.13 signatures.
