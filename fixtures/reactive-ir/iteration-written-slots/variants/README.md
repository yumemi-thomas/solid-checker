- `proto-alias-short`, `proto-alias-deep` (review R58): the iterator patched through `Object.getPrototypeOf([])` held by 2 and 16 `const` aliases, under a non-global key. - ADR 1013, the callback behind a `const`: `handed-timer-callback-alias` (`const again = run; setTimeout(again, 0)`, `run` an arrow): the timer's callback is named, has no `this`, and the slots stay exact: proved SC2001 (Chrome warns: oracle case `iteration-timer-callback-alias`). Uncertifiable: `handed-timer-callback-alias-this` (the aliased function reads its `this`) and `handed-timer-callback-alias-let` (the alias names a `let` two writes may fill).
- ADR 1014, the callback as a member of a `const` object literal: `handed-timer-callback-member` (`const bundle = { cb: () => {} }; setTimeout(bundle.cb, 0)`): the member is the arrow written there (ADR 0279's facts: nothing writes a member of that name, every reference of the holder reads a member, no export), the slots stay exact: proved SC2001 (Chrome warns: oracle case `iteration-timer-callback-member`). Uncertifiable: `-member-written` (an assignment writes a member named `cb`), `-member-escaped` (`Object.assign(bundle, …)`), `-member-getter` (an accessor: the callback is what it returns), `-member-method-this` (a method that reads its `this`), `-member-spread` (a spread after the property).
- ADR 1014, the review's holes (each proved SC2001 on the first build, uncertifiable now; Chrome: oracle case `iteration-timer-member-replaced`): `-member-computed-write` (`bundle[key] = function () { … this … }`, the key no literal and no constant), `-member-this-assign` and `-member-this-define` (a method of the literal hands its receiver to `Object.assign` or `Object.defineProperty`), `-member-quoted-duplicate` (`{ cb: f, "cb": g }`; `tsc` rejects the duplicate, so the fixture expects that error).
- ADR 1014, the review's fourth probe (the first three proved SC2001 on the build 3f33a1a15, all uncertifiable now; Chrome: oracle case `iteration-timer-member-method-added`): `-member-method-added` (`bundle.init = function () { Object.assign(this, { cb() { … } }) }; bundle.init()`), `-member-method-added-define` (the same with `Object.defineProperty(this, "cb", …)`), `-member-method-borrowed` (`bundle.init = other.f`), `-member-this-method` (a method of the literal stores such a function with `this.later = function () { … }`; already uncertifiable before, kept as the `this` side of the same refusal). Still proved: `-member-class-this` (a class inside the member's arrow stores through its own `this` in its constructor: the instance, never the holder).
