# iteration-written-slots

**Claim (ADR 0349, ADR 0803).** A program writing the array iterator visibly (`patch.ts`) has no exact array pattern of a primitive: `const [s, set] = createSignal(1)` may hold anything the patched iterator hands it. `body-write`'s `set(2)` and `s()` are uncertifiable (SC9012, `tuple-iteration-written`), never SC2001. Chrome: quiet, the patch hands back a no-op setter (pattern `types/s04-local-setter-iteration-written`). Without `patch.ts` the same body is a proved SC2001 (Chrome REACTIVE_WRITE_IN_OWNED_SCOPE).

Variants (each `patch.ts` beside the same body):
- `next-alias`: `IP.next = f` through `const IP = Object.getPrototypeOf([][Symbol.iterator]())`, a spelling ADR 0349 misses. Uncertifiable; Chrome quiet.
- `reflect-alias`: `Reflect.set(AP, Symbol.iterator, f)` through `const AP = Array.prototype`. Uncertifiable; Chrome quiet.
- `class-prototype` (negative): `Foo.prototype.bar = 1` on a project class spells `prototype`, and ADR 0282's census clears it. Proved SC2001; Chrome warns.
- `named-key` (negative): `Object.assign(Array.prototype, { zzz() {} })` writes a literal key that is not iteration's. Proved SC2001; Chrome warns.
- `key-alias`: `AP[k] = f` through `const AP: any = Array.prototype`, a key no literal names. Uncertifiable; Chrome quiet.
- `hook-object`: the slots leave a hook in an object (`return { count, setCount }`); `setCount(2)` is uncertifiable at the call, not only at the hook's reference.
- `prop-value`: a caller passes a withdrawn slot's read as a prop (`value={level()}`, `value={state.x}`) and the child reads it in its body (`createSignal(props.value)`). The slot stays a source, so the reads keep their rows, but the prop's backing is unproven: SC1001 uncertifiable, `read-backing-unproven`, never a violation from a slot the patch may have replaced. Chrome warns here (the patch replaces only setters).
- `open-compute`: a memo whose compute calls a withdrawn slot. The slot may be any function, so the memo's provenance is open (ADR 0665): SC5003 uncertifiable, `async-provenance-unproven`, at the JSX read.
- `prop-value-intact`, `open-compute-intact` (negative): the same without `patch.ts`. Proved SC1001 twice; certified.
- `function-escaped`: a `Function` held in a parameter runs a string that patches iteration (pattern `types/s03`); no write spells it, ADR 0801's census (code from a string) withdraws the slots. Uncertifiable.
- `compared-prototype` (negative): `!(proto = Object.getPrototypeOf(obj)) || proto === Object.prototype`, a prototype only compared, as router and store code writes it: proved SC2001; Chrome warns.
- `uncalled-accessor`: `${count}` of a withdrawn slot. upstream_compat's uncalled-accessor arm takes `count` for the accessor; the row is held by place: SC1005 uncertifiable, `tuple-iteration-written`. `uncalled-accessor-intact` (negative): proved SC1005.
- `global-alias-hook`: the patch reaches `Array.prototype` through `const g = globalThis; g.Array.prototype` under a key no literal names, and the hook returns a 3-tuple the patch reorders (Chrome: `now` is the setter, REACTIVE_WRITE_IN_OWNED_SCOPE). The global object handed on withdraws the hook's slot: `now()` is uncertifiable.
- `handed-seen-listener` (negative): `bindEvent(window, ...)` into a project function that only calls `target.addEventListener` with a parameterless arrow: seen code that hands nothing on. Proved SC2001.
- `handed-listener-param` (negative): the caller's listener passed through (`addEventListener(type, handler)`) is read at the call that hands the window on: the literal reaches nothing. Proved SC2001 (`handed-bind-reads-window` does reach it).
- `handed-unseen`: the same call into a function with only an ambient declaration: unseen code receives the global object, so the slots are withdrawn. Uncertifiable.
- `handed-proto-writer`: `itSet(Array.prototype, Symbol.iterator, f)` into a project function that writes `p[k] = f`; the patch hands back a no-op setter. Uncertifiable; Chrome quiet. `handed-assign-open`, `-assign-source`, `-reflect-set`: `Object.assign(p, {[k]: f})`, `Object.assign(p, s)` or `Reflect.set(p, k, f)` in the helper, the patch yielding the setter first. Uncertifiable; Chrome warns (`set(2)` reads, `s()` writes) and the rows cover it. `assign-computed-intact` (negative): that helper with no intrinsic handed on. Proved SC2001.
- Reviews R2 and R7 (ADR 0803 step 2), each uncertifiable: `handed-map-function` (`[[code]].map(Function.apply.bind(Function, null))`: a standard function calling what it is given is no seen code), `handed-call` (`patch.call(null, globalThis)`), `handed-timer` (`setTimeout(patch, 0, globalThis)`), `handed-stored-map` (`new Map([[1, Array.prototype]])` written back out), `handed-global-stored` and `handed-global-returned` (the global object kept or returned, then written).
- `handed-call-seen` (negative): `listen.call(null, window, "resize")` into a project function that only calls `addEventListener`: the shifted argument reaches seen code that hands nothing on: proved SC2001.
- `handed-signal-held`: `Array.prototype` kept in a signal and written back out of it. The runtime hands back what it keeps, so it is no seen code that keeps nothing. Uncertifiable; Chrome quiet.
- Review D3, each uncertifiable: `handed-listener-this` (a function listener that mentions `this`), `handed-listener-event` (an arrow listener that reads its event), `handed-on-handler` (`window.onresize = (event) => ...`), `handed-timer-this` (a timer's callback gets the window as `this`), `handed-window-this` (`window.open()`: a window method off the closed list runs with it as `this`).
- `handed-window-seen` (negative): a listener that reaches nothing, `scrollTo`, `getComputedStyle`, `onresize = null`, and timer callbacks that never mention `this`. Proved SC2001.
- `handed-default-view`: `document.defaultView` is a window by its type, and its `Function` runs a string that patches iteration. Uncertifiable; Chrome quiet. `handed-default-view-intact`, `-optional` (negative): the value only tested and asked for `getComputedStyle`, a destructured `top` and a member `parent` typed no window; `view?.getComputedStyle(...)`, a window's method by key. Both proved SC2001.
- Review D4, each uncertifiable: `handed-any-default-view` (`(document as any).defaultView`: an `any` value under a window name may be the window) and `handed-object-listener` (a `{ handleEvent }` listener is no function literal the checker can read). Sloppy `this`: fixtures `sloppy-this-dependency` and siblings.
- Reviews R19a to R58 (the settler and the callbacks read at the hand-off): `variants/README.md`.
