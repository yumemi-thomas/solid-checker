# The project sets `paramsWrapper` (ADR 0324 refusal)

`paramsWrapper` replaces the object `useParams()` returns (`dist/index.js:1306`). A project that spells it (or `queryWrapper`, `wrapParams`) outside the router's own files leaves the premise unapplied project-wide (`SC9012` stays). Router is the published `@solidjs/router@2.0.0-next.26` byte for byte (MIT; digest `e67af539…04d6`).
