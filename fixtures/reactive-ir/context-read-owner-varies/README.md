SC4002 claims Solid's ContextNotFoundError, which `useContext` throws only after its owner check (ADR 1177). `Varies` reads a default-less context in an `onLoad` handler under a `Show` a timer opens: SC4001 is uncertifiable (`owner-varies-by-caller`), a run with no owner may come first and throw NO_OWNER_CONTEXT (Chrome does), so SC4002 is uncertifiable, `owner-check-throws-first` (main: a violation). `Body` reads it in the component body, under the render's owner: SC4002 stays a violation. `BodyAndHandler` (a function the body calls and `onClick` runs, ADR 0577): the owned body run comes first, SC4002 stays a violation.
