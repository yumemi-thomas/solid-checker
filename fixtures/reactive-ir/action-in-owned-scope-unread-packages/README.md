# action-in-owned-scope-unread-packages

**Claim (ADR 0972).** An installed package the build does not read as source can call Solid's `action` itself: `reachpkg`'s `runStep(cb)` is `action(function* () { cb(); })()`, and its manifest names no Solid package, so a development build does not read it (a standard build reads none). Chrome (rc.21, the pattern lane's `pkgaction/reach-*`) throws `ACTION_CALLED_IN_OWNED_SCOPE` at `runStep(() => {})` in a component body, a memo's compute and a `createRoot` body, and the checker was silent. Each call into such a package's code is now a site of SC2002, decided from the package's source:

- **Uncertifiable** (`package-may-call-action:<why>`, never a violation: nothing proves the package calls an action) where the call may run under an owner or nothing places it, and the package's closure is not clear. `ReachBody`, `ReachMemo`, `ReachRoot`: a call, `ReachNamespace`: through a namespace import, `ReachNew`: a `new`, `ReachTag`: a tagged template, `ReachRender`: a component the package exports, rendered (its body always runs under an owner), `ReachValue`: the package's function handed on as a value (where it runs is not followed), `ReachThroughPackage`: `wrappkg`, whose own closure loads `reachpkg` (`reaches-solid`). `DynamicLoad`: `dynpkg` loads `import(name)` (`dynamic-load`); `UnknownGlobal`: `envpkg` reads `process`, which no `lib.es*`/`lib.dom*` file of the pinned TypeScript declares (`unknown-global`); `MissingSource`: `lostpkg` re-exports a package that is not installed (`missing-source`).
- **Silent** where the role allows an action (`ReachTimer`: a timer callback, `ReachHandler`: an event handler, `ReachValueTimer`: the function handed to `setTimeout`, `ReachValueHandler`: the function as an intrinsic element's event handler; Chrome is quiet on `pkgaction/reach-timer`), where the package's closure is clear (`PureBody`: `purepkg` and its relative import name no Solid package, load nothing by a computed name and read only the libraries' globals; Chrome quiet on `pkgaction/pure-body`), and where the callee is the project's own (`Shadowed`: a local `runStep`).

`InlineBody` is the second hole the probes for this ADR found: `action(function* () {})()` calls the action an `action(…)` call returns, with no binding, and SC2002 had no site for it (Chrome throws `ACTION_CALLED_IN_OWNED_SCOPE`, `pkgaction/inline-body`). It is a violation now; `InlineHandler` stays silent. The same form inside a package the build reads as source reaches the project's call through ADR 0949 (`pkgaction/src-inline-body`).

`node_modules/reachpkg`, `purepkg`, `dynpkg`, `envpkg`, `lostpkg` and `wrappkg` are **not** published bytes: each is written for this fixture, a declaration file and the module the closure walk reads, with a manifest that names no Solid package. `node_modules/solid-js` and `@solidjs/*` are the manifests of `flush-universe-package-hand-off`. `.solid-checker/runtime.json` closes the program boundary.
