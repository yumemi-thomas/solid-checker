# returned-dispatch-effect-apply

**Claim (ADR 1235).** A function declared in an effect's apply and called there runs what its returned value holds on that call's stack: a method of the returned object (`Chain`), a returned arrow (`Curried`), a function element of a returned array run by `forEach` through the callback's parameter, inline or held by a `const` named once (`Element`, `HeldElement`), and an element's method (`ElementMember`). Each is an SC1001 violation at the call (main and ADR 1233: SC9012 uncertifiable `handed-member-read`; Chrome rc.21 STRICT_READ_UNTRACKED on the grid's `handed-*` effect-apply programs). Uncertifiable: `HeldTwice` (the holder is named twice, ADR 0282), `InMemo` (tracked, the dispatch obligation stays), `Deferred` (a microtask's run). Clean: `InHandler`. Stub: `effect-cleanup-disposal-only`'s.
