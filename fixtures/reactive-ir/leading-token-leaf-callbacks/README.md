# leading-token-leaf-callbacks

**Claim (ADR 0376).** A leaf owner's callback, a closed adapter's argument, a factory callee, a callee called inside the leaf and a callback argument the callee runs name a function only as its identifier. A compound span's entity names its leading token, so `onSettled(outer.cb)`, `onSettled(identity(outer.cb))` and `onSettled(factory.bind(null))` were SC3001 violations resting on `outer`'s or `factory`'s body, and `getFn()()` and `setN(makeUpdater())` were certified because `getFn` and `makeUpdater` are clean. All five are now SC9012. Controls: `onSettled(factory())` and `onSettled(outer)` stay SC3001, `setN(updater)` is SC3001 (the setter runs its updater, ADR 0210). Owners: `leaf_owner_operations_for_file`, `callback_argument_function`, `helper_forbidden_operations`, `argument_body_operations` in `cleanup.rs`. Stub: `fp-owner-leaf-helper-after-await`'s (published rc.9 typings).
