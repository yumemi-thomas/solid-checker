# change-checkbox-handler

**Claim (ADR 1148).** The `change` handler of a literal `<input type="checkbox">` or `<input type="radio">` is delivered by its click activation alone: a user's click, the Space key or an arrow key on the host's stack, or a call the dispatch census already counts (`el.click()`, `label.click()`, `dispatchEvent`). So its body is an event callback with no owner, as a `click` handler's is. A text control is delivered `change` by any way the focused element leaves (`blur()`, `remove()`, `disabled = true`, Solid's own unmount), in the call (ADR 0642), and a checkbox retyped to text is one.
