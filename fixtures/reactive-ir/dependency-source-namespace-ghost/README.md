# dependency-source-namespace-ghost

**Claim (ADR 0376).** ADR 0322 binds a namespace import's static member through an entity at the member's property span or, when its symbol covers the span, at its whole span. The whole span's entity otherwise names the leading token, the namespace, and `readLater`'s redirect had bound that symbol, so `Widget.ghost` (declared in the typings, absent from the runtime file) counted as bound and the project was certified. It is now SC9005. The bound counterpart (every member binds, certified) is `dependency-source-namespace-import`. `dep-ns` is `dependency-source-namespace-import`'s two-file package with one more declaration (`ghost`); runtime configuration as there. Owners: `symbol_redirects` in `source_redirects.rs`; `namespace_import_redirected` in `package_requirements.rs`.
