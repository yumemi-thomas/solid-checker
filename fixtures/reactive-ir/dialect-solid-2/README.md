# dialect-solid-2

Half of a retired pair (the 1.x half is gone): the package declaration preserves the real 2.0.0-rc.0 `createEffect` overloads and `node_modules/solid-js/package.json` selects 2.0 (the stub selects the reviewed dialect; it does not authenticate installed runtime bytes). It pins the native Solid 2 findings in `App.tsx`: `SC7001` violations for the missing apply function (`OneArgument`) and for casts that leave a provably non-callable effect argument, an uncertifiable `SC7001` under a `"use server"` directive, `SC7002` for an async `{ sync: true }` memo, `SC4001` for the module-level `createReaction` tracker `trackReaction` and for `SeedOrApply` (not for `trackOpaqueReaction`: its callback is `wrapReaction(...)`'s result, a project call's value, and a call's literal is not the callback since ADR 0345 review D; docs/open-work.md records the lost recall), and `SC1001` for the apply callback's untracked read; calls the published typings already reject stay silent. The retired contract-catalog checks (ADR 0027) no longer apply.
