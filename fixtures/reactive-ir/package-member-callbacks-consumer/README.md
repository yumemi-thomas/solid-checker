# A consumer of member-path callbacks

Written to pin that a contract calling a member of an argument (`callHandler`, `callBoundOnly`; `from: {arg: 1, path: ["0"]}`) folds the member as an inline call exactly when the call's syntax names it: handler, pair and bound-pair calls `SC1001`, whole and stored arguments clean, open variant `SC9005`. Package contracts are removed (ADR 0312), so nothing is folded. Today the only finding besides the SC9014 notice for the rc.0 stub is the reference case `Direct`: a project-local `readCount()` read of `count` in a component body, an `SC1001` `strict-read-untracked` violation (status `violation`). `Handler`, `HandlerPair`, `BoundPair`, `BoundWhole`, `BoundStored` and `BoundOpen` are silent. `callHandler` is declared as `@kobalte/utils@2.0.0-alpha.0` does (`JSX.EventHandlerUnion` reduced). The `solid-reactivity.json` beside the stub is inert.
