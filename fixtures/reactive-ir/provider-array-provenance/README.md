# Returned provider array provenance

An exact factory returns one array literal of closed object literals. Each query
is an exact source-discovered synchronous arrow; map/forEach has the standard
library declaration identity and an inline synchronous arrow whose entire
expression body invokes exactly one member of its element parameter.
Body/eager/apply consumers read the original
signal slots. Tracked and inert queries remain non-violating. Definition timing
obligations are retained separately.
TypeOnly and TypeOnlyHelper carry only a declared SourceAccessor type: neither
may become a violation. Exact arrow identity is separate from runtime source
identity. Both the selected targets and the per-analysis runtime-origin set
participate in retained result identity.

Aliased/escaped/replaced arrays, helper parameters, stored or async callbacks,
async members, element aliases, open elements, alternative returns and other
array methods, conditional/block callbacks and maps in named/stored callback
definitions withhold transport. Ordinary direct helper calls compose exact
entry to the selected arrows; HelperApply pins that path. The companion veto project independently
pins each mutator and reflection form. No new nodes or element dataflow are
inferred. Member stability remains conditional under ADR 0273.

The reduced signal/memo/effect/context declarations are copied unchanged from
accessor-provenance's claim-bearing published rc.13 signatures. Published-typing
validation uses the retained real rc.13 packages, not these stubs.
