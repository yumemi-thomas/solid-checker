# never-rendered-component

ADR 0373, the vacuous case of ADR 0214: in a closed program (`package.json` is `private`, ADR 0193) whose module census is complete, a component no reference renders or calls receives no props. Its prop reads are no SC1001 obligation (the props are proven static, so SC1007 asks nothing either), and a handler drawn only from its props (`onClick={props.onPick}`, `{...props}`, `{...omit(props, "label")}` through a `const`) is no SC4001 obligation.

`Card.tsx`: `Unused` (unexported), `UnusedExported` and `UnusedArrow` (an unnamed arrow censused through its `const`) are quiet. `UnusedNamed` keeps its obligations: a named function expression's own name says nothing about the `const` that holds it. `Rendered` is the referenced control: its tag passes a static label, so its read is quiet, and its forwarded handler keeps the attribute obligation. `Exposed.tsx` keeps them: `Main.ts` hands its namespace out unnamed (`Object.values`). Variants: `open` publishes `main` (an open program, ADR 0193) and `glob` loads modules through `import.meta.glob`; both keep every obligation.
