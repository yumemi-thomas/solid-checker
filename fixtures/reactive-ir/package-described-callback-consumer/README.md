# A consumer of a described callable's callback items

Written (ADR 0152) to pin that `pipe` hands back a function running the call's own arguments: a read in a body `SC1001`, in JSX or unused clean, an open-`returns` control `SC9005`. Package contracts are removed (ADR 0312), so nothing places the callbacks: every `count()` read inside a `pipe` callback is an `SC1001` `strict-read-untracked` uncertifiable result, called or not (`UntrackedPipe`, `TrackedPipe`, `UnusedPipe`, `OpenPipe`), and `UnusedAccessorPipe` gives `SC9011`, plus the SC9014 notice for the rc.0 stub. The old positive/negative split is no longer pinned. `pipe` is declared as `@solid-primitives/utils@7.0.0-next.4` declares it (the same `App.tsx` with the published package beside `solid-js`/`@solidjs/web` `2.0.0-rc.9` is `tsc` clean). The `solid-reactivity.json` beside the stub is inert.
