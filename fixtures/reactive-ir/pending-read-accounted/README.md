# pending-read-accounted

Claim (ADR 0838): every read of a source not proved synchronous is accounted for per pending rule (SC5001, SC5003, SC5008): a row of that rule at the read (or whose `origin`/`pending_origin` is it), an SC9012 at the read (SC5001 only since ADR 0926), or a reason ruling the rule out; else uncertifiable, blocker `async-read-unaccounted`. Positives (a walk ends with no row): `TwoReadsOneCall`, `RewrittenHelper` (written binding), `GeneratorHelper`, `MixedBoundPath` and `TwoCallers` (R1/R6: a placed call speaks for its own path; a cut path leaves the read its rows, ADR 0835), `BareProbe` and `HelperBareProbe` (R18: no `Loading`, rc.21 warns), `ExportedHelper` and `ShorthandReference` (R17, D9: an unseen caller), `EscapedComponentFlush` (R2h: an escaped body's role is no reason), `StoreKeysCaught` (R2h: `Object.keys(store)` is a site), `GetterCaught` (R2h: a getter run by `held.v` in a `try`). Negatives: `HandlerRead`, `CoveredRead`, `ProbeRead`, `ComputationRead`, walk-decided `HandlerHelper`, `TimerHelper`, `CoveredProbeHelper`. Stubs as in `handed-closure-pending-read`, plus `Loading` and `isPending` from rc.21.
