# A denied event's handler never takes the host-delivery proof

The ruling on ADR 0642, measured in Chrome: any way a focused element leaves delivers `blur`, `focusout`, `change` and, with an IME,
`compositionend`, Solid's own unmount included; an attribute write delivers `beforetoggle`, an insertion `load`, a constructor `formdata`.
No program needs a call on the hazard list. Each handler's read and write are uncertifiable, dispatch or not.
