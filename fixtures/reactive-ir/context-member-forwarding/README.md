# Context member forwarding

One default-less context with exactly one closed literal provider transports
its exact orientation signal through a wrapper's single return of an immutable
intermediate binding with pure truthiness/nullish tests. Const simple member
destructuring permits only immediate calls of every selected identifier.
Body/eager/apply consumers
retain their own execution role; tracked reads remain non-violating.

This is an exact wrapper handoff to the existing project-wide receiver census,
not arbitrary object return/alias dataflow. Default/rest/computed/nested patterns,
escaped destructured members, ambiguous providers, mutations and escapes stay refused. The
companion refusal project pins those boundaries independently. Primitive stubs
are unchanged reduced published rc.13 signatures from accessor-provenance.
