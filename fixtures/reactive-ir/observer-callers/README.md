# observer-callers

**Claim (ADR 0614).** `resolve` and `until` guard on the observer, so an action's first step answers to its callers and an IIFE in a flow child's JSX runs under the render effect: both are obligations rather than certified clean. Measured on rc.17: `FromTracked` and `InFlowJsx` throw `RESOLVE_IN_REACTIVE_SCOPE`; `FromHandler`, `PastYield` and `FlowHandler` report nothing. Since ADR 0834 the IIFE in a flow child's tracked JSX (`InFlowJsx`) is placed in that insert's tracked computation, so its `resolve` is a proved `SC2004` violation (rc.21 in Chrome: "Cannot call resolve inside a reactive scope" in `<For> › div.children`, then REACTIVITY_HALTED); `FlowHandler` stays silent.
