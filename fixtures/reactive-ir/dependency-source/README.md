# Dependency source (ADR 0284)

`.solid-checker/runtime.json` selects `dep-hooks` as a dependency source, so the package's runtime source is analyzed as project code and no package-behavior claim is needed. `LabelNow` binds to the file `exports` selects under the `solid` condition and reaches `readNow` (`SC1001` violation at the call); `LabelMemo` defers into a memo (silent); `Badged`'s own read is located in the package (not reported); `Greeting` still transports (the package's open `Object.assign` vetoes only objects the package creates, ADR 0273) and reports its `account.user()` read as an `SC1001` violation. `runtime.json` declares a browser development host.
