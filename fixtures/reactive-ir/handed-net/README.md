# handed-net

**Claim (ADRs 0770-0779).** Each program writes, acts or reads through a value no fact resolves, Chrome reports it, and the build before certified it: a member past the first step (`n1`, `n4`, `n9`), a value handed to a helper at a tracked position (`r1`, `a1`, `a9`, `a13`, `h2`, `run-local`), a hook behind `.call`, `.bind`, a rebound or computed callee or a chosen hook (`c1`, `c7`, `c9`, `c11`, `c12`), a `Function.prototype` or `Reflect.apply` hand-off (`s6`, `s8`, `push-apply`). Each is uncertifiable, none a violation. `handed-net-guards` holds the programs the net must leave alone. At a tracked position with no boundary: an alias, a literal member or an anonymous callback over a pending source is uncertifiable (`c1-let`, `c1-literal`, `c3-wrapper`, `c6-tagged`). A logical-assignment callee and a function an instance holds after an await are SC9012 (`c5`, `c7-this`), and a pending read on a later task is SC5001 (`p1-timer`, `p2-timer`).
