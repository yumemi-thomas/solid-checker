# SC1001 flip: design note

Read at `origin/claude/flip-reads` `ef46d0ac6`. Line numbers are from that commit. No Rust was built: designs are argued from the code,
and every "measured" means a program run through `tsrs`, real Chrome and the `r5007` checker build. The read path has not changed since that
build, apart from SC8003's `syntax.rs`.

Probes are in `/tmp/sc-scratch.noindex/flip-reads/research/probes/pN/<id>/App.tsx`, Chrome results in `pN-chrome.json` beside `probes/`. To
rerun: `chk.sh <dir> [bindir]`, `tsc.sh <absolute dir>`, `node gen.mjs pN.json probes/pN`. Corpus role data: `sc1001-roles.txt`,
`sc1001-chains.txt`.

## Read this first

1. **The nesting fix in the plan is too wide.** "A primitive's callback excuses only functions inside it" turns a read in `createEffect`'s
   apply inside a hook into a helper read. That is `useOnboardingTour.tsx:97`, plus `h10`, `h11`, `h12`, all true warnings. Narrow it to
   window-inheriting primitives (step 5).
2. **`unplaced_run` has a hole.** It looks only outwards from the site. A plain helper called from a getter is certified and Chrome warns
   (`u01`, `u03`-`u07`, `u14`, `u15`). Closing `c01`-`c06` alone leaves this open (step 3).
3. **Setter callbacks are a new proved violation, not only a lost warning.** `setStore(fn)` and `setSignal(fn)` run `fn` on the setter's
   stack. In an apply that warns, and the checker certifies it (`r11`, `r18`, `r19`, `z01`) (step 6).
4. **`reconcile` takes a key.** The plan's "reconcile takes 1 argument" is wrong: `setStore` takes 1 argument. Only the 5 path-form programs are
   rejected. `setSt(reconcile(v, key))` passes `tsc`, and the column stays live (`r11` false clean, `r15` false positive).
5. **12 `open-defects.json` entries are not defects**, and the `<Dynamic>` ones will not leave the list when the hint is fixed, because
   `patterns.mjs:130` never sees the hint (step 0).

## 2. Order of edits

Each is one commit, tree green after it.

**Step 0, tooling, no behaviour.**
- `patterns.mjs:130`: treat a finding whose hint holds `NO_RUNTIME_WARNING` (`checker.mjs:218`) as `runtimeSilent` when Chrome reported none of the
  rule's codes. The lane has the Chrome record, so this is a measurement, not a trust.
- Reword the 5 `k-*-reconcileKey` programs to `setSt(reconcile(v, key))`, because the rejected spelling is an artifact of the setter's arity.
- Take `e411-show-fn-child` and `f01-notreadyerror-manual` out with a reason, or reword them (both `rejected`).
- `make fuzz-patterns ARGS=--update`, and read the diff.

**Step 1, guards.** Add the programs in section 5 to `scripts/fuzz/flip-read.mjs` first, so the old build's failures are on record.

**Step 2, widen the reads.** `unreached_read`, `:2347`, `:5449`: `named_at_tracked_position` stays, the test becomes
`unplaced_run(..) || inside_class_member(..)`. `ExecutionRole::Unknown` stays. Blocker `function-run-unplaced`.

**Step 3, helpers reached from a hidden call.**
- `call_result_reads`: the first gate becomes `!enclosing_render_function(..) && !unplaced_run(file, call.span, lookup)`.
- `:391`: `!(inside_class_member(..) || unplaced_run(..))`.
- At such a site `execution` must be `Unknown`, and `read_execution_role` gives `callee_roles.unplaced` there. Assert it.

**Step 4, `inheriting_call_role`.** Change only the reporting tail. When `at_call` reports, climb with `write_roles::climb_in_place_layers(file,
call.callee, lookup)`, then look at the function holding `climb.at`:

| Holder of `climb.at` | Answer |
|---|---|
| A component body, an apply, a control-flow child, `ref` (the arm already proved it) | keep `at_call` |
| `fresh_stack_callback_call` answers (timer, microtask, `.then`) | `DeferredCallback`, **proved silent**: a fact decides it |
| Anything else (`window.__go =`, object on a host, handed to a project helper) | `Unknown` |

Do not touch `:817`. Direct reads rely on it.

**Step 5, `inside_non_component_function`, narrowed.** The primitive test at `:1281` excuses every enclosing function only for a primitive whose
callback the scheduler runs. For `dialect.callback_inherits_calling_window(primitive, index)` (`createRoot`, `runWithOwner`, `createRevealOrder`) it
excuses functions **inside** the callback. Add the Dialect question to the test, nothing else changes. Corpus reach is 0, because no row has that
primitive in its chain. This step exists so `h()`'s summary claims the read at its call, which keeps `n13`, `n22`, `n23`. If those hold after step 4
alone, skip step 5: it has 16 callers.

**Step 6, setter callbacks, reads only.** New arm in `semantic_role_before_awaits`, inside `!classifying.contains(&write_classification_marker())`,
beside `inheriting-call`: a function that is argument 0 of a call whose callee is an exact setter (`self.setters`' symbol through the lookup), or the
key of a `reconcile` that is itself that argument, takes the role of the setter call. That gives EffectApply in an apply, silent in a handler or timer.
A key on a held `reconcile` (`r13`) is `Unknown`. Blocker `function-run-unplaced`.

**Step 7, own-store reads in a setter.** `dev.js:6501` checks `!inDraft(target)`, so a read of the setter's own store in its own callback is silent in
any window (`z05`, `z06`, measured in an apply). When the read's root symbol is the store its setter came from, answer `DeferredCallback`, not the
call's role. Without this step 6 adds a false positive.

**Step 8, mounts.** After SC5001's commit: check `r-dyn` keeps `v@8`, and that every `<Dynamic>` row in section 3 now has the no-window hint.

**Step 9, what no rule row holds.** Q4, Q5 and C-D4 have no row in the plan (section 6).
