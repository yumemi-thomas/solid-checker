# F0 design note: a resolved call drops the net only if its target's summary is complete

Read at `origin/claude/flip-reads` `ef46d0ac6`. Nothing here was built. "Measured" means `tsrs`, real Chrome and the `r5007` checker on one program. Probes:
`/tmp/sc-scratch.noindex/flip-reads/research/probes/p4`, Chrome in `p4-chrome.json` (24 of 24 pass `tsc`).

## Read this first

1. **The report's predicate is too narrow.** "No call of a parameter, a parameter's member, a `let`, or an unresolved member" misses member **reads**. `t5`, `t6`
   read `s.v` on a captured store parameter. The test that works is simpler: **any reference to a captured value**.
2. **Parameter and alias are not enough.** `t8` (`const m = n`), `f17` (`const box = { f: n }`), `f13` (`arguments`), `f08` (rest), `f09` (default) all need the
   walk through local `const`s.
3. **The drop is not the only way in.** `handed_value` returns false on a call expression, so `useT(p.n).read()` has no obligation to keep (`v08`, `f01`). `x.forEach`
   over a transported array has none either (`f02`). F0 needs three edits, not one.
4. **F0 and the census do not share one predicate.** They share helpers and ask two questions (section 7).
5. Keep the predicate's use in `reactive_analysis.rs`, not in `result_reads.rs`: result chunks record each table entry they read, and a transitive answer read there
   would go stale in the daemon.

## 2. The predicate

`incomplete(f)` is true if `f`'s body, nested functions included, holds any of these, or an edge from `f` reaches a function that does. Compute locally for
functions reachable from a transported target, then close over `edges`. A cycle stays complete only if nothing in it is open.

**Default is open.** Write it as a `match` whose last arm says incomplete.

| Form in the body | Answer |
|---|---|
| Any reference to a **captured value**, see below | open |
| Reference to `arguments` | open (`f13`) |
| Callee or member root is a `let`, or a binding assigned anywhere | open (`t13`, `f16`) |
| `this.x()` or `this.x` | open (`f11`) |
| A call in `transported_calls` | its target, through `edges` |
| A call to a project function, a primitive, an accessor, setter or action with a row, or a standard-library declaration | followed |
| A call with no row but an obligation of its own at that location | followed (kui `current.watch()`, `useQuery.ts:273`). Needs the obligation lists, which is another reason to finish the check in `reactive_analysis.rs` |
| Own parameter of `f`, called or read | followed: `add_invoked_parameter_reads` and `add_parameter_member_reads` answer at the call (`f05`, `f06` open today, measured) |
| Anything else that calls | open |

**Captured value:** an identifier in `f` whose declaration is outside `f` and inside an enclosing function.
- A parameter of any shape (named, destructured slot, rest, default): open, unless Type Facts proves it primitive (`lookup.proven_primitive`). `f14`, `useT(id: string)`, must stay certified.
- A `const` with a function initializer: followed, the edge carries it (`t10`).
- A `const` a source row owns: followed (`f15`: stays V).
- Any other `const`: walk its initializer with the same test, bounded; past the bound, open (`t8`, `f17`).

A module-level `const` is not captured. Module fields fall to the call rule (`reg.f()`: `t14`, `q4`).

## 5. The warning direction

F0 only keeps obligations, so it cannot lose a violation, and adds none. Risk: a kept handed obligation over a reported read. `covered` (`reactive_analysis.rs:332`)
removes it only for `UNRESOLVED_HANDED_READ`, so `UNRESOLVED_HANDED_MEMBER` gives V and U at one site. Both are true. Expect it in snapshots; do not filter it.

No corpus finding is at risk. Corpus cost is uncounted here; the report's name-based bound is 400.

## 6. How it could go wrong

| Failure | Program | Guard |
|---|---|---|
| A false clean through a `const` alias | `t8`, `f17` | Unit test, before the drop |
| A false clean through a nested function's parameter derived from a captured one | `[n].map((f) => f())` (`f18`): `n` is the reference, so it is caught; test it | `f18` |
| A false clean on a recursive pair | `a` calls `b` calls `a`, `b` calls a parameter | Close over `edges`, do not memo a partial answer |
| Own parameter treated as followed when the call is not direct | target reached by transport, called with a spread | `add_invoked_parameter_reads` handles spread at `argument.spread`; add one program |
| Stale in the daemon | edit `useA`, `useB`'s target unchanged | Compute every build, read only in `reactive_analysis.rs`; run `make ir-edit-fuzz` and `make ir-read-lint` |
| Type-proved primitive is a lie: `id as any` | `useT(n as any as string)` | Cast is the program's; note it as a premise or refuse `any`-cast arguments at the call |
| False positive | none: U only | |

## 7. How F0, the census and SC9012 fit

See `sc9012-census.md` section 7: F0 owns **handed values at a call of a resolved target**. Order: F0, F-C, F-D, census, F-B.
The shared piece is the position helpers, not a predicate: F0 asks "does running `f` reach unknown code", the census asks "does parameter `i` keep its value followed". `keep(f) { window.__k = f; }`
is complete for F0 and open for the census.
