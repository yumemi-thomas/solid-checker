## How to read this (method, switch, definitions)

**Corpus and builds.** The frozen rc.21 corpus v2 (`solid-checker-rc21-frozen-v2/apps`, 23 apps, 34 projects, `scripts/corpus/rc21-manifest.json`), one checker process per project, `--runtime-target browser --runtime-build development --rendering csr` (the manifest's configuration, "dev"), daemon off, release build. Head = branch `claude/writer-cause-census-m0`; base = `dba9d3cee` (main with ADR 1114 family 3 slices A–F, the build the branch is cut from). Std mode (`--runtime-build production`) is not measured here.

**Row.** A finding with `kind: uncertifiable` whose `analysisContext` holds `:prototype-` (`package-may-call-action:<reach>:prototype-<kind>`): the SC2002 rows of ADR 1114 family 3. This is how the design report counted its 136,756 rows (slice E, head-e4); this head also carries slice F, so its total is larger. Other rows that move when a writer is left out (SC1002 after-await rows read `prototype_writers_any` too) are reported apart.

**Any-name writer.** A package root (the directory the backend keys by) whose closure `GlobalWrites::prototype_any_name` holds for, and that is not clear (`PackageReach::is_clear`: no hazard, no Solid): `PackageReachIndex::prototype_writers_any_name`. An *effective* writer is a counted root that is not clear. A row of a kind that asks of an any-name writer exists while the project has one.

**Causes.** Why `prototype_any_name` holds, per file, as classes (the scan names them only where the census or the class what-if is on; `solid-facts/src/module_reach/writer_causes.rs`):

| class | what the syntax shows |
|---|---|
| `escape:<head>/<shape>[@receiver]` | the global object handed on. `<head>` is the name it was reached through (`globalThis`, `window`, `self`, `top`, `parent`, `frames`, `global`, `this`, `document`) or, for a route, the member the scan takes for the window (`source`, `view`, `defaultView`). `<shape>` is what the parent does with it (`pattern`, `alias[<uses>]`, `member:<name>`, `computed-read`, `argument:<callee>`, `new:<callee>`, `return`, `assign`, `store`, `coerced`, …, `branch:` when it came through `||`, `??`, `?:`). `@receiver` is what a route's member was read off (`regexp`, `literal`, `param`, `this`, `member:<name>`, `call`, `binding`, `pattern`). |
| `generated:<kind>` | code built at run time: `eval`, `eval-literal`, `timer-string`, `function-literal:{empty,this,const,other}`, `function-dynamic`, `function-member:<name>`, `function-value`, `constructor-chain`, `constructor-literal:<body>`, `constructor-other` |
| `prototype-handed-on/<shape>`, `prototype-key`, `prototype-pattern` | a built-in's prototype handed on whole, written under a key nothing decides, or bound by a pattern the scan does not read |
| `unread:<blocker>` | code nobody read (`MissingSource`, `NativeModule`, `Unparseable`, `DynamicLoad`, `ManifestUnread`, `ClosureLimit`) |

The *first problem* a row's message prints (`unknown-global Buffer`, `dynamic-load module`) is the walk's first problem in walk order for the root, the Q2 question "may it reach Solid". It says nothing of why the root is a writer (Q1): no unknown global sets `prototype_any_name`.

**The switch.** Both are internal, read from the environment once, and change nothing when unset (proved byte-identical below).
- `SOLID_CHECKER_WRITER_CENSUS=1` prints one JSON line on stderr: every root that may write under any name (its name, real directory, whether the program loads it by the backend's flag, whether it is counted and clear, the first problem and every problem by blocker, its causes by file and count, the project files that import it and how), every root a project file imports with the writers its walk read, and what the program loads that no import names.
- `SOLID_CHECKER_WHATIF_WRITER_DROP=<file>` (roots, one per line) and `SOLID_CHECKER_WHATIF_WRITER_CAUSES=<prefix,…,unloaded>` leave roots out of `prototype_writers_any`: a root whose every cause has a class a prefix names, a root the program does not load (`unloaded`), or a listed root. They move verdicts and are a measurement, never a proof. Nothing else is touched: the named writers (`prototype_writers`) stay, so the rows only a named writer asks for stay.

**How rows are measured.** A project's rows depend on the writer set only through whether an any-name writer is left (and, for the sites that ask of a writer by name, the named ones, which the switch leaves alone). So per project two runs are measured: the baseline (census on) and the **floor** (every counted writer left out). A mechanism set `S` frees `baseline − floor` rows of a project exactly when it decides every effective writer, and nothing otherwise; the offline step decides which, from the census, and the claim "nothing otherwise" is then measured, not assumed: **V2** runs every project with two or more writers with all but one left out and compares its rows with the baseline. Where a table says *measured* it is from a run of the checker; *ceiling* means the mechanism is taken to decide everything its definition can (an upper bound on what the mechanism built to the design frees); *estimated* is a figure from the design report or a size that is not measured.
